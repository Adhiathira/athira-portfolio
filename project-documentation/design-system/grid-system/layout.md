# Layout Brief: Brand Name — Entry / Splash Screen

---

## 1. Overall Page Structure

This is a single-screen **splash / entry gate** — not a scrollable multi-section page. The entire composition fits within one viewport with no scrollable content. The structure has two focal zones:

- A **centered modal-like content cluster** in the upper-middle third of the screen
- A **pinned bottom action** anchored to the viewport floor

The page is intentionally sparse — close to 70% of the viewport is negative space (a light background).

---

## 2. Header / Navigation

**There is no traditional header or navigation bar.** The logo and brand name serve as the entry point identity, embedded directly into the centered content cluster. No top bar, no nav links, no hamburger menu.

---

## 3. Hero / Central Content Cluster

This is the visual and functional core of the page. It sits vertically centered, slightly above the true midpoint of the viewport — classic optical centering.

**Layout:** Single-column, center-aligned stack with tight vertical rhythm:

1. **Logo mark** — a circular illustrated icon, roughly 80–90px wide, displayed at roughly 1.5× the text size to create clear hierarchy. The logo has a visible stroke/border giving it a card-like presence.
2. **Brand name** — in small-caps or uppercase tracking, smaller than expected — treated more as a label than a headline. This keeps the tone understated and refined.
3. **Descriptor copy** — 2–3 lines of body copy in a narrow measure (roughly 280–300px wide), centered. The type is small (≈14px equivalent), regular weight, muted — not high contrast. This copy block feels intentionally quiet, subordinate to the logo.
4. **Primary CTA** — a pill-shaped button with generous horizontal padding, light fill, dark text, centered below the copy. There's visible breathing room (≈20–24px gap) between the copy and the button.

The entire cluster spans roughly **300px wide × 260px tall**, sitting in a sea of negative space. The proportional restraint is deliberate — the content is a window, not a statement.

---

## 4. Below-Hero Content Sections

**There are none.** This is a pure entry screen with no additional content sections. The page's only job is to gate entry.

---

## 5. Footer Layout

No traditional footer. Instead, there is a **single text link pinned to the bottom center** of the viewport:

- Secondary CTA — small, uppercase, spaced tracking, underlined
- It sits roughly 40–48px from the bottom edge
- Very low visual weight — it recedes into the background intentionally, offering an alternative path without competing with the primary CTA

This creates a **two-choice decision architecture**: the primary action button above, the secondary escape hatch below.

---

## 6. Notable Layout Patterns

| Pattern | Description |
|---|---|
| **Full-viewport lock** | The layout is viewport-locked, not document-scrollable. The experience is contained. |
| **Optical vertical centering** | Content sits slightly above mathematical center — a classic typographic centering technique that feels more balanced to the eye. |
| **Extreme negative space** | ~70% of the viewport is empty background. The content cluster feels precious and deliberate — almost fragile. |
| **Anchored secondary action** | The secondary link is position-fixed to the bottom, creating spatial separation from the primary CTA without a competing visual hierarchy. |
| **Narrow measure constraint** | Copy is forced into a narrow column (≈300px), creating a tall, intimate text block rather than wide comfortable reading. This is a stylistic choice that feels more like editorial design than web design. |
| **No structural chrome** | No borders, cards, containers, or background panels frame the central content. It floats freely on the flat background color. |

---

## Spatial Rhythm Summary

The page reads **top-to-bottom** in one beat: **logo → name → description → primary action**. The rhythm is slow — generous gaps between each element encourage the eye to linger. The bottom link acts as a silent counterweight, pulling the composition into a balanced tension between center-mass and floor anchor. The overall feeling is **gallery-like**: quiet, confident, unhurried.
