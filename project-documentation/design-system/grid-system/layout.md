## 6. Notable Layout Patterns

**Full-bleed imagery throughout:** Nearly every section uses edge-to-edge photography as its primary layout element. There are no contained image boxes with padding — images extend to viewport boundaries or column edges without constraint.

**Floating / overlapping elements:** The nav floats over the hero. Section headings appear to overlap image sections during scroll transitions. A sign-up modal (if present) is a layered overlay — not part of the native layout but consistent with the brand's two-layer visual logic.

**Sticky/transforming header:** The wordmark migrates from the hero into the nav zone as you scroll, a common editorial pattern that preserves maximum hero real estate while keeping navigation accessible.

**Asymmetric weighting:** Text columns are consistently narrower than image columns, reinforcing that this is a visual-first experience — copy supports the imagery rather than competing with it.

**Vertical rhythm through restraint:** Sections breathe. There's generous vertical space between elements within sections, creating a slow, considered reading pace rather than an information-dense one.

**Typographic scale contrast:** Massive display type placed directly against small caption-weight labels creates strong hierarchy without needing color or graphic elements — pure typographic contrast drives the layout.
