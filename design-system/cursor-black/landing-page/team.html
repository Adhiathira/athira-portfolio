Principles

How we operate.

Security over convenience

We will never add a feature that weakens security for the sake of UX. If the secure path is harder, we make the secure path easier — not the insecure one.

CLI-first, always

Every feature ships as a CLI command first. Web dashboards are optional views over the same data. The terminal is the contract.

Transparent about limitations

We document what Ghost cannot protect you from. No tool is perfect. We would rather lose a prospect than have a customer who trusts Ghost in a context where it cannot deliver.

Open by default

Core cryptography is open source. Audit protocols are published. Third-party security audits are shared publicly. Trust is built with receipts.
