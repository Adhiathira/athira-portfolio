Core capabilities

Built for teams that ship close to the metal.

Every feature designed for the developer workflow. Not the compliance dashboard.

01

Zero-knowledge encryption

Secrets are encrypted on your machine before they leave. Ghost's servers never see plaintext. Your keys, your data.

ghost encrypt --scope team
02

Automatic rotation

Schedule secret rotation on any interval. Ghost rotates, notifies affected services, and logs the event — no manual intervention required.

ghost rotate --every 30d
03

Immutable audit trail

Every access, rotation, and share event is logged with timestamp, actor, and context. Cryptographically signed. Tamper-evident.

ghost audit --tail 100
04

Team namespaces

Isolated vaults per team, per environment. Production secrets are invisible to developers with staging access. Fine-grained RBAC.

ghost namespace prod --read-only
05

CI/CD integration

Native GitHub Actions, GitLab CI, and CircleCI plugins. Inject secrets at build time. Zero env var leakage in logs.

ghost inject --env production
06

Local dev proxy

Run `ghost run` to prefix any command with secrets injected as environment variables. No `.env` files. No accidental commits.

ghost run -- npm start

Getting started

Up and running in four commands.

No web UI required. No configuration files. Terminal-native from day one.

  1. 01

    Install Ghost CLI

    Install the Ghost CLI via npm or Homebrew. Available on Linux, macOS, and Windows (WSL).

    $ npm install -g ghost-cli
  2. 02

    Initialize your vault

    Create a new project vault. Ghost generates a zero-knowledge key pair locally and stores the public key on our servers.

    $ ghost init --project my-app
  3. 03

    Store your first secret

    Push any secret to your vault. Encrypted with your local key before the request leaves your machine.

    $ ghost set STRIPE_KEY sk_live_...
  4. 04

    Run your app with secrets injected

    Prefix any command with `ghost run --`. Secrets are injected as env vars for the process lifetime only. Zero disk writes.

    $ ghost run -- node server.js
