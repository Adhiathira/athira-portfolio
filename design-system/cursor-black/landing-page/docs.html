Installation

Install the Ghost CLI on your machine. Available on Linux, macOS, and Windows via WSL.

Requirements

Ghost CLI requires Node.js 18+ or can be installed as a standalone binary with no runtime dependency.

Note
For production environments, the standalone binary is recommended. It has no Node.js dependency and starts faster.

Install via npm

terminal bash 
$ npm install -g ghost-cli

Verify the installation:

terminal bash 
$ ghost --version
ghost-cli/2.4.1 darwin-arm64 node-v20.11.0

Install via Homebrew

terminal bash 
$ brew tap ghost-systems/ghost
$ brew install ghost-cli

Quick start

Get a project vault set up in under two minutes.

terminal — getting started sequence bash 
# 1. Authenticate (creates a device keypair)
$ ghost auth login

# 2. Initialize a project vault
$ ghost init --project my-app

# 3. Store a secret (encrypted locally before upload)
$ ghost set DATABASE_URL "postgres://user:pass@host/db"

# 4. Run your app with secrets injected
$ ghost run -- node server.js

How zero-knowledge encryption works

Ghost uses a hybrid encryption scheme. When you store a secret:

  1. A symmetric data key (AES-256-GCM) is generated locally.
  2. Your secret is encrypted with this data key.
  3. The data key is encrypted with your device's public key (X25519).
  4. Only the double-encrypted blob is sent to Ghost's servers.
Security guarantee
Ghost's infrastructure has cryptographic access to zero secrets. Even a full database breach exposes only ciphertext that cannot be decrypted without your private keys, which never leave your device.

CLI Reference — ghost init

Initialize a new project vault in the current directory.

usage bash 
ghost init [flags]

Flags:
  --project <name>     Project vault name (required)
  --team <slug>        Associate with a team namespace
  --env <name>         Environment tag (default: development)
  --no-gitignore       Skip .ghost gitignore entry
