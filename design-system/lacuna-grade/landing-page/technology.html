Architecture

Designed from the signal path outward.

Every component in Lacuna Grade begins with a single constraint: add zero latency to the signal you are measuring. The result is an instrument, not a processor — one that observes without interfering.

A passthrough architecture with zero insertion loss.

The core innovation in Grade is a differential tap circuit that reads the signal without joining the signal chain. Your source flows unaltered from input to output while Grade observes on a separate measurement path that never touches the master signal.

System Layers
  • 01 Analog Front End Differential tap circuit with >120dB CMRR. Captures signal characteristics without introducing any electrical load on the source path.
  • 02 ADC Stage 32-bit high-speed analog-to-digital conversion at 192kHz with precision clocking. Temperature-compensated reference voltage for drift-free measurement.
  • 03 DSP Analysis FPGA-based real-time spectral analysis, latency mapping, and anomaly detection running at full channel capacity without approximation.
  • 04 Network Layer Gigabit Ethernet with an embedded web server. Streams measurement data to the browser dashboard at 60fps with configurable alert webhook support.
  • 05 Dashboard UI Zero-install browser interface with per-channel signal meters, spectral visualization, and configurable alert thresholds. No app required.
