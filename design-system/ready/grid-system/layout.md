# Brand Name — Layout Brief

## 1. Overall Page Structure

The page is a long-form marketing scroll with 8–9 distinct sections. The rhythm alternates between **text-centered headline moments** and **immersive product UI showcases** — creating a push-pull between editorial breathing room and dense, feature-rich product windows. Background stays a consistent warm off-white/linen throughout, making the dark product UI windows pop as the primary visual elements.

---

## 2. Header / Navigation

Minimal fixed bar. **Logo left-aligned** (brand name in clean text), no navigation links in the middle, **avatar stack right-aligned** (5–6 circular user avatars overlapping slightly). The navigation deliberately carries almost zero chrome — the avatar stack is the only right-side element, acting as a social-proof signal rather than a utility nav. Very low height, approximately 48–56px.

---

## 3. Hero Section

**Three-layer composition:**

- **Background layer:** full-width warm off-white/linen canvas
- **Middle layer:** a native app-style sidebar panel floats left of center at roughly 35% viewport width — this is the "native app" chrome, using the light sidebar aesthetic
- **Foreground layer:** a large modal/detail sheet slides in from the right and overlaps the sidebar, extending to the right edge of the viewport. This sheet has a deep **dark gradient header**, creating a dramatic color contrast against the linen background

Above the UI stack, centered headline copy reads at display scale. A small accent badge floats in the top-right corner of the headline area as an inline decorative element — suggesting multiplayer presence directly in the typography.

Below the headline, a short centered subtitle paragraph, then the overlapping UI windows begin — no explicit Primary CTA button in the immediate hero.

The hero is **not full-bleed**. The product windows appear as floating objects within the page canvas, creating a sense of depth rather than a flat background image.

---

## 4. Content Sections

### Section 2 — Contextual Feature Panel + Detail View
A **two-panel overlapping composition**: a small primary view panel floats left, and a white document/detail panel sits center-right and overlaps it. The left panel recedes; the right panel dominates. Below this, a large centered headline with a short centered body paragraph — classic editorial break.

### Section 3 — Feature Cards Row (Horizontal Scroll / Overflow)
Three to four **equal-width feature cards** presented in a horizontal strip that bleeds to the viewport edges. Each card is a rounded rectangle with a gradient background. Cards are partially visible at the edges — implying lateral scrollability or overflow cropping. This is the densest feature showcase moment.

### Section 4 — "Feature A" — Asymmetric Feature Block
**Left-aligned headline** (large, 2–3 lines), with body text below it taking approximately 40% of the width. Below that, two large feature cards sit in a **side-by-side layout** but with slight vertical offset — the left card is taller and positioned lower, the right card is higher. Each card has a gradient background with white text and a nested UI component mockup inside. Decorative hand-drawn accent marks (small arrow/chevron sketches) float in the negative space between cards, adding informality.

### Section 5 — "Feature B" — Single Feature Highlight
**Center-weighted asymmetric block**: A large gradient feature card occupies roughly 60% of the horizontal space, left of center. To the upper right, a smaller floating dark dropdown widget overlaps the adjacent whitespace — suggesting a second, contextual UI element. Below this card cluster, a centered large headline with body text.

### Section 6 — "Feature B" + "Key Differentiator" — Two-Card Feature Stack
Two overlapping rounded-rectangle cards at different scales and vertical positions. Left: a smaller gradient event card. Right: a taller gradient sidebar card that extends higher. They overlap slightly. Below, a **nested UI mockup** — a dark application window — sits inside the left card with the dark background creating a window-in-window illusion.

### Section 7 — Full App UI Showcase
This is the **most expansive product moment**: a near full-width application window — dark-themed — showing the complete primary interface view. The window has realistic chrome (traffic light buttons, tab bar), occupies roughly 80–85% of the viewport width, and is centered with visible page margin on both sides. A light gradient bleeds into the background behind it, softening the hard dark edge. Above, two small pill-shaped feature callout tags float centered.

### Section 8 — CTA / Closing
Centered, minimal. Large display headline stacked on two lines. Below, two short centered paragraphs at body scale. No buttons — the call to action is pure editorial, relying on copywriting weight rather than UI chrome.

---

## 5. Footer

Extremely spare. Two lines of content:
- **Left:** "Brand Name — [Tagline]" in small body text
- **Right:** Social media icon links only

Full-width, no columns, no link lists. Matches the restraint of the header — the design doesn't try to recapture attention at the bottom.

---

## 6. Notable Layout Patterns

**Floating / overlapping product windows** — The core layout language. Product UI elements are never contained in a grid cell; they float as layered objects at different z-depths, creating the illusion of actual software running on screen. This is the signature visual system.

**Alternating density rhythm** — Wide-breathing headline sections (centered text, generous whitespace) alternate with dense product UI sections. This gives the eye relief and emphasis control.

**Hand-drawn accent marks** — Small sketched arrow/chevron doodles appear in the negative space between feature cards, breaking the otherwise polished digital aesthetic with a human, informal touch.

**Presence indicators** — User avatar bubbles, name badges, and real-time selection highlights appear throughout product UI mockups, consistently reinforcing the core product thesis without needing to state it in copy.

**Consistent page margin** — Even in the most expansive UI showcase sections, approximately 7–10% page margin is maintained on each side. Nothing is truly full-bleed; the canvas always breathes.

**Dark product windows on warm linen** — The color contrast between the dark-themed application window and the warm off-white background is the single highest-contrast moment on the page, used strategically for the feature-complete showcase near the bottom.
