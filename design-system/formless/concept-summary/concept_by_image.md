## Visual Identity
The palette is a strict monochrome — pure `#000000` backgrounds with `#ffffff` text — punctuated by a single brand accent: a radial teal-green glow (`#1a7a5a` at its brightest core) that shifts to deep blue (`#0a3d6b`) in the closing section. Typography pairs Neue Haas Grotesk Display Pro for all headings with Inter for body copy — a neoclassical grotesque display face against a utilitarian workhorse, creating institutional weight without warmth. Motion is minimal and mechanical: a single easing curve (`cubic-bezier(0.4, 0, 0.2, 1)`) governs all transitions at 0.3s, with a slower 0.5s on cards.

## Hero Section
The hero occupies the full viewport height with a pure black base layered by a soft radial ambient glow (`#0d4a35` → `#1a7a5a`) positioned in the lower-center of the frame, functioning as atmospheric depth rather than an image. Text is left-anchored: a 60px / 60px line-height display heading in Neue Haas Grotesk Display Pro weight 500 occupies the left column, while a 20px Inter paragraph sits in the right column at the same vertical baseline, creating a deliberate two-column split with spatial tension. Two pill-shaped CTAs appear below the heading — one ghost (transparent fill, white 1px border) and one filled white — both using `border-radius: 9999px` with `12px 32px` padding. The lower portion of the hero resolves into a full-width brand lockup: an oversized polygon icon and the FORMLESS wordmark at ~95px, filling the viewport width entirely and functioning as a typographic anchor rather than navigation.

## Content Sections
The content body uses a sticky scroll pattern for the services panels — three sequential two-column splits where the left column holds a large 3D rendered object and the right column contains an oversized numeral (in ~95px Neue Haas), a service title at 30px, and two body paragraphs at 20px/28px Inter — all separated by a thin vertical rule (`#1a1a1a`). Section margins are wide and consistent at 244px horizontal, creating a contained editorial column within the 1536px max-width container; section padding-bottom reaches 200px, making whitespace the dominant spatial element. A case studies section breaks the column logic with an irregular three-column overlapping card grid — a code snippet card, a portrait, and an office image — anchored by massive display headline text spanning the full width above. Image treatment uses 3D-rendered glass geometry (prismatic, refractive) rather than photography, rendered on pure black with no container borders, which removes any card-frame visual from the objects.

## Footer Section
The footer is not a traditional multi-column link grid — it functions as a closing full-bleed CTA section: a single centered oversized headline ("Join the network today.") at display scale, a single text-link with an arrow-right icon below it, followed by a horizontal row of four social icons (X, LinkedIn, Instagram, Discord) at bottom-left. The brand lockup reappears at large scale — the hexagon icon and FORMLESS wordmark — as the visual terminal point of the page. Legal text (`© FORMLESS`, Privacy Policy, Terms of Service) runs in a three-item row at the bottom edge in `#a0a0a0` muted grey, the only typographic downsizing in the footer. Background treatment echoes the hero: the same radial glow appears, this time shifted to blue (`#0a3d6b`), making the footer a chromatic bookend to the hero's teal.

## Design Principles
- **Single easing system:** Every animated element — buttons, links, cards, nav — uses `cubic-bezier(0.4, 0, 0.2, 1)` exclusively. No variation in easing character; only duration changes (0.2s / 0.3s / 0.5s).
- **Ghost → fill button inversion on hover:** The primary CTA pattern uses a transparent ghost button that fills to solid white on hover, inverting the text to black — a high-contrast state change requiring no color tokens beyond the existing white/black palette.
- **Opacity-based link interaction:** Nav links and icon links use `opacity: 0.6` on hover rather than color change — the entire interaction vocabulary for links is a single opacity step, keeping the white-on-black palette unbroken.
- **Radial glow as the only non-monochrome element:** All chromatic expression is delivered through a single atmospheric device — the teal/blue radial gradient — which never appears in text, borders, or UI elements, only as ambient background depth.
- **Typographic scale as hierarchy driver:** With no use of color, weight variation is the sole differentiator — `font-weight: 500` on Neue Haas Display for headings, `font-weight: 400` on Inter for body, and scale jumps from 20px body to 60px h1 to 95px display lockup create a three-tier hierarchy without any other visual marker.

## Distinctive Qualities
The most unusual structural choice is the **dual brand lockup** — the FORMLESS logotype appears at full-viewport width both at the bottom of the hero and again as the terminal element of the footer, functioning as a visual frame that opens and closes the page rather than being confined to the nav. This is rare: most sites use the logo only in the navigation; here it becomes a compositional device at display scale.

The **sticky scroll services pattern** uses a thin vertical rule as the sole dividing element between a photographic/3D left panel and a text right panel — no card containers, no background swaps, no padding boxes. The division is purely typographic and linear, which is architecturally unusual in scroll-jacked layouts that typically use background color alternation to signal section changes.

The **ambient glow color shift from teal to blue** between hero and footer is a deliberate chromatic arc — the only color change on the entire page — creating a narrative through a single hue rotation across a 100% black canvas without introducing any additional colors.
