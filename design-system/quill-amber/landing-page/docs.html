Authentication

All Lōmen API requests are authenticated using a Bearer token. Pass your API key in the Authorization header with every request.

# Example: curl request with API key
curl -X POST https://api.lomen.io/v1/analyze/rt60 \
  -H "Authorization: Bearer lmn_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d @room.json

Room Object Schema

Every analysis endpoint accepts a room object in the request body. Dimensions are in metres; surface assignments reference material IDs from the library endpoint.

{
  "dimensions": {
    "width": 5.2,
    "length": 6.8,
    "height": 2.7
  },
  "surfaces": {
    "floor": "mat_carpet_medium",
    "ceiling": "mat_gypsum_plain",
    "walls": "mat_concrete_painted"
  },
  "speakers": [
    { "x": 1.0, "y": 0.0, "z": 1.1 },
    { "x": 4.2, "y": 0.0, "z": 1.1 }
  ],
  "listening_position": { "x": 2.6, "y": 4.0, "z": 1.2 }
}
Parameter Type Description
dimensions object Room width, length, height in metres. All three required.
surfaces object Material ID strings for each surface. Use GET /materials to list available IDs.
speakers array XYZ coordinates in metres. Required for SBIR analysis. Optional for RT60 and modal.
listening_position object XYZ of the listener. Required for SBIR. Defaults to room centre if omitted.

RT60 Analysis — POST /v1/analyze/rt60

Returns Sabine and Eyring reverberation time values at all 7 octave bands (63 Hz through 8 kHz), along with ISO 3382 compliance flags for common room types.

# Response shape
{
  "method": "sabine+eyring",
  "bands": [63, 125, 250, 500, 1000, 2000, 4000],
  "rt60_sabine": [0.72, 0.58, 0.41, 0.35, 0.31, 0.28, 0.25],
  "rt60_eyring": [0.68, 0.54, 0.38, 0.33, 0.30, 0.27, 0.24],
  "compliance": {
    "iso3382_studio": "pass",
    "iso3382_broadcast": "fail",
    "recommendation": "Add 8m² broadband absorption at 63 Hz"
  },
  "analysis_time_ms": 340
}

Material Library — GET /v1/materials

Query the 628-profile material library. Filter by category, name substring, or minimum absorption coefficient at a target frequency band.

Query param Type Description
category string Filter by category: carpet, gypsum, glass, concrete, wood, foam, fabric.
name string Partial name match, case-insensitive.
min_alpha float Minimum absorption coefficient (0.0–1.0) at the specified band.
band integer Octave band for min_alpha filter. One of: 63, 125, 250, 500, 1000, 2000, 4000.
limit integer Max results (default 20, max 100).

API endpoints

Complete endpoint
reference.

POST

/v1/analyze/rt60

Run Sabine and Eyring RT60 analysis. Returns 7-band decay times and ISO 3382 compliance flags. Completes in under 400 ms for standard room geometry.

POST

/v1/analyze/modal

Calculate axial, tangential, and oblique room modes using the Rayleigh method. Returns mode frequencies, XYZ node positions, and clustering warnings below 300 Hz.

POST

/v1/analyze/sbir

Speaker boundary interference response prediction. Requires speaker coordinates and listening position. Returns null-frequency curves and severity flags at each cancellation point.

GET

/v1/materials

Query the material library. Filter by category, name, or minimum absorption coefficient. Returns absorption coefficients at all 7 octave bands plus ISO 354 reference data.

GET

/v1/export/{analysis_id}

Export a completed analysis as PDF, CSV, or JSON. PDF output follows ISO 3382 report structure. Accepts ?format=pdf|csv|json query parameter.

GET

/v1/rooms/{room_id}

Retrieve a saved room object and its analysis history. Rooms are persisted across sessions within your workspace.
