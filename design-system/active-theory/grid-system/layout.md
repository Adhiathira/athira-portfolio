## Notable Layout Patterns

- **No traditional grid** — the layout rejects column-based structure in favor of spatial composition within 3D space.
- **Floating, layered elements** — the nav, scroll text, and 3D objects all exist on separate z-planes, overlapping without interference.
- **Extreme restraint in UI chrome** — the only text elements are the nav capsule and the scroll prompt. This maximizes immersion.
- **Full-bleed dark canvas** — no margins, no container, no content box. The browser edge is the composition boundary.
- **The pill nav** is an interesting compression pattern — two links in one button container reduces nav footprint to near-zero while maintaining discoverability.

## Spatial Rhythm and Hierarchy

The visual hierarchy is: **3D hero object → scroll prompt → nav**. The brand object commands the most visual weight through scale, luminosity, and material richness. The scroll prompt is secondary — instructional but subdued. The nav recedes furthest, present but not competing. This is a hierarchy designed for an audience already familiar with the brand — it rewards curiosity over legibility.
