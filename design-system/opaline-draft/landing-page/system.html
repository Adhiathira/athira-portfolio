The system

Every tool the specification record requires.

Forme covers dimensional tolerances, surface finish call-outs, material chains, STEP import, supplier views, and version control — all structured so they can be queried, compared, and handed off without transformation.

Core capabilities

A specification tool is only as good as the constraints it enforces.

STEP Import

Import nominal values directly from STEP geometry.

Forme reads dimensional features from STEP files and populates the base record automatically. Nominal values are extracted; your engineers assign tolerances. No manual data entry, no transcription errors, no disconnection between the 3D model and the specification record.

Supplier View

A filtered handoff — not a redacted PDF.

The supplier view shows exactly what the manufacturer needs for their process. The filter is structural: it exposes call-outs by process type (machining, finishing, assembly) rather than manually hiding fields. Your IP stays in the record; the supplier gets a coherent specification for their scope.

See how it works →
→ assets/system-supplier-view.jpeg

Revision control

Every change is ancestry, not replacement.

When a tolerance changes, the previous value is preserved as a revision branch — not overwritten. Compare across revisions inline. Know who changed what, when, and why. The record accumulates every engineering decision made on the part, from first entry to final sign-off.

Supported standards

The references your parts already live by.

Dimensional

ISO 286 — Limits and Fits

Full H/h tolerance grade system. Clearance, transition, and interference fits with automatic class assignment.

Surface

ISO 1302 — Surface Texture

Ra, Rz, Rq, Rt. Call-out symbols with manufacturing process linkage and lay direction specification.

Geometric

ASME Y14.5 — GD&T

Flatness, circularity, cylindricity, profile, orientation, location, and runout tolerances. Datum reference frames.

Material

ISO 6892 — Tensile Properties

Link material specifications to mechanical property requirements. Yield strength, UTS, and elongation tracked per alloy.

Coating

ISO 2081 — Electroplating

Deposit thickness specification with minimum local thickness and corrosion class call-outs.

Custom

Company-specific standards

Define and register internal tolerance standards. Custom fields with validation rules and approved value sets.
