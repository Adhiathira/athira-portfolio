# Brand Name Homepage — Layout Brief

## 1. Overall Page Structure

The page flows through approximately **10–12 major sections**, arranged in a single-column vertical stack with a dark background that runs edge-to-edge throughout. The visual rhythm alternates between full-width text-centric sections and sections that combine text with product UI screenshots. There is a strong sense of vertical breathing room — sections are generously padded, never feeling crowded. The background color is monolithic, creating a seamless tunnel effect as you scroll.

The headline uses a two-color typographic treatment — light for the primary line and a vivid accent color for the secondary line. This color split is the single strongest visual signal on the page.

It is cropped at the bottom edge, implying continuation — inviting scroll. The screenshot has a slight top-rounding (card treatment) and sits inside what appears to be a subtle gradient glow or vignette emanating from behind it. The background behind the hero has a radial gradient: dark fading toward a richer mid-tone near the center-bottom, giving warmth and depth.

The hero is approximately **two viewport heights** when accounting for the scrolled-in product screenshot.

## 6. Notable Layout Patterns

- **Persistent consent bar** — A small rounded dark card anchored to the bottom-left viewport edge persists across all scroll positions. Fixed position, low visual intrusion.
- **Scroll-triggered opacity fade** — The feature cascade section uses opacity-as-depth, where items lower in the list appear faded. This is a scroll-driven animation that rewards slow reading.
- **Color-coded section identity** — Rather than using different background colors per section, accent color is used as section identity — each footer column has its own label color, each feature card has its own screenshot background color. The dark background stays constant; color is applied surgically.
- **Full-bleed dark canvas** — No section breaks with light space or dividers. Transitions between sections rely purely on vertical spacing and typographic scale shifts.
- **Screenshot cards as visual anchors** — Product UI screenshots are always contained in colored rounded-corner cards (not raw screenshots), giving them a "framed" quality that separates them from the page background.
- **Typographic hierarchy through weight and opacity** — Throughout the page, the hierarchy system is: full-light bold for headlines, light regular for body, muted for supporting text. Color is used for brand moments and Primary CTA, not for general content differentiation.
