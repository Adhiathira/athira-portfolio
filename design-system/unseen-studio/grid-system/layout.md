# Layout Brief: Entry / Splash Screen

## Overall Page Structure

This is a **single-screen splash/entry gate** — not a scrollable page. The entire composition lives within one viewport with no scrollable content below. The function is purely ceremonial: to welcome and route the visitor before they enter the actual site.

---

## Header / Navigation

**There is no conventional header.** The brand identity (logo + name) is placed centrally in the composition, not anchored to a top edge. Navigation is entirely absent from this screen — by design, this is a pre-navigation moment.

---

## Hero / Entry Section

The entire viewport *is* the hero. The layout uses a **strict vertical center alignment** with all elements stacked along a single invisible central axis.

**Spatial hierarchy from top to bottom (centered column):**

1. **Logo mark** — An abstract brand symbol, rendered in outline with filled forms. Roughly 120×80px. Visually dominant, personality-forward.
2. **Brand name** — Company name in widely-tracked, small-caps uppercase. Tight to the logo below, creating a logo lockup.
3. **Descriptor tagline** — 3-line body copy, centered, medium reading width (~280px equivalent). Comfortable vertical gap separates it from the lockup above.
4. **Primary CTA button** — "Primary CTA" in a pill/rounded-rectangle container with a light fill and subtle border. Generous horizontal padding, vertically separated from the tagline by roughly one body-text-height of space. A directional glyph adds motion to an otherwise static composition.

The central cluster occupies approximately the **middle 40% of the viewport height**, leaving large, equal breathing room above and below. This is intentional — the negative space *is* the design.

---

## Secondary / Utility Element

At the very **bottom center** of the viewport, anchored near the floor:

- A small, underlined text link: "Secondary CTA"

This is typographically subdued — lowercase or small caps, minimal weight. It functions as an escape hatch for accessibility/preference, clearly secondary to the primary CTA above. The large vertical distance between the primary CTA and this link reinforces the hierarchy: primary path center-stage, secondary path nearly out of frame.

---

## Footer

**No footer exists.** The secondary CTA link serves the footer's utilitarian function but is not a footer in the structural sense.

---

## Notable Layout Patterns

| Pattern | Description |
|---|---|
| **Full-bleed background** | A solid background color fills the entire viewport edge-to-edge with zero margin, border, or frame |
| **Centered monolith** | All interactive and identity elements collapse into a single vertical spine — zero asymmetry, zero grid complexity |
| **Extreme negative space** | Upper ~35% and lower ~35% of the viewport are completely empty, making the center cluster feel suspended |
| **Spatial anchoring via contrast** | The secondary link is pinned to the bottom, creating a top-to-bottom tension with the centered cluster — the page breathes between them |
| **No scroll affordance** | No scroll indicator, no arrow, no visual cue that anything exists below. The experience is intentionally sealed until the user chooses to enter |

---

## Designer's Read

This layout is an exercise in **reduction as brand statement**. The spatial grammar communicates: *we are not in a hurry; we are confident; we are quiet about it*. The centered symmetry, the oversized void, and the restrained typographic scale all encode the same message as the brand tagline. The layout *is* the brand positioning.
