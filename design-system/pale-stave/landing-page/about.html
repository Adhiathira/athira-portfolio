The Project

Built from the site up.

Calliper began as a set of field notes — specifically, the notes that did not fit any existing tool. A tape measure reading attached to a photograph. A condition note that needed to reference an archival drawing. A maintenance schedule that needed to know when the condition was last assessed.

Origin

The record that no tool could hold.

Conservation documentation happens in buildings that resist documentation. Surfaces are close. Light is uneven. Access is temporary. The surveyor has a tablet, a tape measure, a reference drawing, and about forty minutes before the scaffolding comes down.

No existing documentation tool was built for this. Project management tools were built for tasks, not measurements. CAD tools were built for drawing, not recording. Spreadsheets were built for data that stays still, not for field entries that accumulate across decades of visits.

Calliper is built for the forty minutes on the scaffold — and for the record that needs to survive forty years of subsequent visits.

Design Principles

What we will not compromise on.

Precision is not optional

A dimension recorded as "approximately 2.4 metres" is not a dimension. Calliper does not accept approximate entries in dimension fields. If a measurement cannot be made precisely, it is flagged as estimated with an accuracy notation — not silently recorded as a number that will be cited as exact.

The record outlasts the surveyor

A documentation system that requires knowledge of the surveyor's notation conventions to be legible is not a system. Calliper records are structured to be legible to anyone who uses the system — not because the surveyor was disciplined, but because the structure enforces it.

No silent fallbacks

When a field cannot be completed — because the datum is unknown, because the material cannot be identified, because the condition cannot be assessed in current access conditions — the record says so explicitly. An empty field is not the same as an unknown condition.

The building is the archive

Documentation does not end when the project ends. Every building that receives conservation attention accumulates a history of visits, assessments, interventions, and observations. Calliper is designed to hold that history — not to produce a report and then be discarded.
