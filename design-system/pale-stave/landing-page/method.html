The Method

Observation, record,
link, report.

Calliper is organized around four acts of documentation — not features. Each act has a defined output. Records from different surveyors on different visits can be assembled without reconciliation because the method holds the structure, not the person.

Reference before record

Every element receives a reference code before documentation begins. This separates the act of identifying what requires recording from the act of recording it. Without reference codes, records from different visits cannot be compared; with them, a building accumulates documentation history rather than disconnected surveys.

Controlled vocabulary, not free text

Condition descriptions use a controlled vocabulary — not prose, not abbreviations invented in the field. A consistent vocabulary means condition records from different surveyors on different projects are comparable. It also means failures can be queried: show me every instance of substrate delamination across all sites in the last three years.

Provenance is not optional

Every attached document carries a source type, a date, and a provenance note. This is the difference between an archive and a folder of files. When a conservation report cites a prior condition assessment, the citation needs to be traceable — back to the surveyor, the visit date, and the instruments used.

Field-first, office-complete

The entry form is designed for a tablet held with one hand, offline, in conditions where you cannot look up from the surface you are documenting. Office review is supported — but nothing in the workflow requires it before the next visit. The field record is complete on its own terms.

The Four Acts

In sequence, not in parallel.

I

Observe

Walk the space before recording anything. Identify what requires documentation. Assign reference codes to elements — wall faces, structural members, openings, material interfaces. The reference scheme is yours; Calliper enforces only that it is consistent within a project and documented in the Survey instrument.

The act of observation is not a preliminary step. It is the first act of documentation — and the one most often skipped. When it is skipped, records from different surveyors cannot be compared, and the building's documentation history cannot accumulate.

  • Element register with reference codes
  • Documentation scope memo
  • Datum record
II

Record

Enter dimensions, conditions, and anomalies by element reference code. The Survey instrument accepts tape measure readings directly — no conversion. The Condition instrument uses the controlled vocabulary. Both are designed for one-handed tablet entry in a space where you are standing close to the surface you are recording.

Records are timestamped and geolocated on save. Voice input and paper transfer are both supported for surveyors who prefer to record on paper and transfer before leaving the site.

  • Dimension strings by element
  • Condition schedule
  • Anomaly log
III

Link

Attach prior surveys, archival drawings, specification documents, and material analysis results to elements by reference code. Each attachment carries a provenance note. Records accumulate: each visit adds to a continuous thread for each element, and the building's documentation history grows without requiring reconciliation between visits.

Linking is not filing. It is the act that turns a set of records into a building archive — one where a query can ask: what has been recorded about this wall face across every visit, by every surveyor, in any instrument?

  • Provenance chain per element
  • Source register
  • Linked document archive
IV

Report

Generate condition assessments, survey summaries, and maintenance schedules from your field entries. Report formats are structured for conservation practice and heritage documentation conventions — not adapted from general project management templates.

The condition assessment format includes: element register with condition grades, failure mode summary, recommended interventions, and supporting evidence (photographs, prior condition records, material analyses). Each section cites the field entries it is drawn from, so the report is always traceable back to the record.

  • Condition assessment (submission-ready)
  • Survey summary with dimensioned drawings
  • Maintenance schedule by element
