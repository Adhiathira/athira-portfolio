REST API

CORE ENDPOINTS

GET
/v1/threats
List all tracked adversary groups with filtering by severity, category, and status. Paginated.
GET
/v1/ioc/lookup
Single IOC enrichment — hash, IP, domain, or URL. Returns actor attribution, MITRE tags, confidence score.
POST
/v1/ioc/bulk
Bulk IOC lookup — up to 500 indicators per request. Returns matched entries with enrichment payload.
WS
/v1/feed/live
WebSocket live feed — subscribe to real-time threat events filtered by severity threshold. Push delivery.
POST
/v1/hunt
Submit a PHANTOM Query Language expression. Execute against the event store and return matching records.
Example Request
# IOC Lookup — Python SDK
import phantom
 
client = phantom.Client(
    api_key="ph_live_xxxx"
)
 
result = client.ioc.lookup(
    value="185.220.101.45",
    type="ip"
)
 
# Response
{
  "value": "185.220.101.45",
  "type": "ip",
  "actor": "APT28",
  "severity": "CRITICAL",
  "confidence": 0.97,
  "mitre": "T1566.001"
}
Query Language

PHANTOM QUERY LANGUAGE

Write precise threat hunt queries against your event history. Full temporal support, MITRE filtering, and regex matching built in.

Example
Find Lateral Movement
SELECT src_ip, dst_ip, technique, ts
FROM events
WHERE mitre_tactic = 'lateral-movement'
AND confidence > 0.85
AND ts > NOW() - INTERVAL 24h
ORDER BY ts DESC
LIMIT 100
Example
APT Attribution Hunt
SELECT actor, technique, count(*)
FROM events
WHERE actor IN (
  'APT28', 'Sandworm', 'Lazarus'
)
AND severity = 'CRITICAL'
GROUP BY actor, technique
ORDER BY count DESC
