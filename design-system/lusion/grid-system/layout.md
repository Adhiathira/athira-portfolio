# Brand Name Homepage — Layout Brief

## Overall Page Structure

The page uses a clean two-zone architecture: a **light-background header zone** above, and a **dark full-bleed hero image** below. The visual contrast between these two zones is the primary organizing principle. The layout feels sparse and editorial — lots of breathing room, deliberate whitespace, nothing decorative.

---

## Header / Navigation

The header is a **four-column-like horizontal band** with generous top padding and no visible border or separator:

- **Far left:** Logo — uppercase, compact, tight to the left edge
- **Center-left:** A large editorial tagline in ~3 lines, roughly spanning columns 2–4. This is **unusually prominent for a nav zone** — it functions as both a headline and a brand statement
- **Far right:** Two pill-shaped CTA buttons (Primary CTA and Secondary CTA) floated right. The first is dark/filled, the second is outlined/ghost. There's also a subtle "—" dash between the headline area and the CTAs, acting as a visual divider

The spatial weight here is asymmetric: left anchor (logo) is minimal, center-left carries significant typographic mass, right side has two compact controls.

---

## Hero Section

The hero is a **full-bleed, edge-to-edge image** that spans the entire viewport width. It sits directly below the header with no gap — the image starts where the light background ends.

- The image itself is a 3D render of sculptural objects on a dark background
- The image occupies roughly **75–80% of the viewport height** — dominating the above-the-fold experience
- There are **no overlapping text or UI elements inside the image** — the image is clean
- The transition from light header background to dark image is abrupt and intentional — a hard edge, not a gradient

---

## Bottom Bar (Hero Footer Strip)

At the very bottom of the viewport, sitting just below the hero image, is a **thin horizontal strip** with:

- Four "+" cross symbols evenly distributed across the full width (at roughly 0%, 33%, 66%, 100%)
- Centered between them: a scroll indicator label in small caps/uppercase
- This strip uses the same light background as the header, creating a **visual sandwich**: light top → dark image → light strip

The "+" symbols echo the shapes in the hero — a conceptual rhyme between UI and content.

---

## Notable Layout Patterns

| Pattern | Description |
|---|---|
| **Hard-edge color split** | Light zone / dark zone with no bleed or gradient — very deliberate |
| **Editorial headline in nav** | The tagline sits in the header but reads at display scale — breaks typical nav conventions |
| **Full-bleed imagery** | Hero image is flush to all edges — no margins, no border-radius |
| **Symmetrical footer strip** | The bottom "+  Scroll Prompt  +" strip is a navigational rhythm device, not a traditional footer |
| **Asymmetric header balance** | Logo (small) + Headline (large) + CTAs (small) creates left-heavy typographic weight |

---

## Spatial Rhythm & Hierarchy

The hierarchy flows: **Logo → Tagline → CTAs → Image → Scroll prompt**. The tagline punches well above its weight — it's sized closer to a hero headline than a nav item, which creates an unusual but confident visual rhythm. The generous whitespace in the header makes the full-bleed dark image land with real impact when the eye reaches it.
