# Brand Name Website — Layout Brief

---

## 1. Overall Page Structure

The page flows through approximately 7–8 major sections in a vertical scroll narrative. The rhythm alternates between **full-bleed cinematic image sections** and **structured content sections** — creating a push-pull between immersive editorial storytelling and clean product presentation. The overall density is low; generous whitespace and large typography give the page a premium, unhurried quality.

---

## 2. Header / Navigation

The header is a **transparent overlay** floating above the hero image — no background, no border. It sits in three distinct zones across the full viewport width:

- **Left zone:** Hamburger + "Menu" label (icon-text pairing)
- **Left-center zone:** Search icon + "Search" label — same treatment as menu, maintaining symmetry
- **Center:** Brand logotype in lowercase — perfectly centered, acts as the visual anchor
- **Right zone:** Three utility icons — language selector with dropdown chevron, user/account icon, wishlist, cart — spaced evenly and tightly grouped

The header is **extremely minimal** — no colored bar, no shadow — blending seamlessly into the hero. There's also a **dismissible announcement banner** at the very top of the page (full-width, centered text, close button on the right) that pushes the header down slightly.

---

## 3. Hero Section

**Full-bleed, full-viewport-height** image carousel. The content is **center-aligned both horizontally and vertically** within the image:

- A small overline label ("Primary CTA") in tight uppercase tracking
- A large serif display headline — very large, dominant
- A short body paragraph below
- A pill-shaped CTA button centered beneath

The text block floats freely over the image with no backing card or overlay box — the image itself serves as the background. There's a **pause control** (‖ icon) in the bottom-left corner, indicating this is an auto-playing carousel. The image has a subtle dark vignette to ensure text legibility.

The overall feeling is **editorial poster** — image-first, text as secondary layer.

---

## 4. Content Sections Below the Hero

### Section 2 — Category Navigation Grid
**White background, high contrast break** from the hero. This section uses a **6-column icon grid** on a clean white canvas:

- Each cell: a category image (transparent/object-style, no background box) centered above a single-line label
- Equal spacing, centered alignment across the row
- A small section eyebrow ("Action Button") in tight uppercase tracking above the grid
- Very open, breathable spacing — this functions as a visual menu more than a content block

### Section 3 — Full-Bleed Editorial Feature
Returns to **full-bleed image**, this time with the Brand Name mark overlaid in **very large display type** centered on a dark cinematic environment. This is purely atmospheric — a brand statement, not a product feature. No CTA visible in the cropped view. The logotype uses an unusually **wide-tracked, custom rounded letterform** that dominates the frame.

### Section 4 — Split Two-Column Feature
An **asymmetric editorial split**: the left ~50% is a dark full-bleed image, the right ~50% is a separate image or content panel. The headline uses a **hand-drawn/brush style display font** — visually loud and unexpected — spanning most of the width. A short descriptor and an underlined text link sit below, center-aligned within the image.

### Section 5 — Split Two-Column Product Feature
Clean **50/50 vertical split** — left half is a light background with typography, right half is a dark full-bleed image. The left panel has:
- Small uppercase overline ("Brand Name Presents")
- Large serif display headline (multi-line, left-aligned)

This is a **static editorial card** with clear left/right balance. The color palette shift between panels creates the column division rather than any border or line.

### Section 6 — Additional Split Features (repeating pattern)
The same **50/50 split pattern** continues for subsequent editorial features. Left and right positions alternate between image and text, creating a **zigzag rhythm** as you scroll. This is a standard but well-executed editorial pattern — each pair of panels feels like a magazine spread.

---

## 5. Footer

**Three-zone structure on a dark background:**

**Top zone:** A locale selector button (flag + region text) floated left, and a **scroll-to-top arrow button** floated far right — both sitting above the main footer columns.

**Middle zone:** Multi-column link grid — approximately 4 columns of navigation links (store locator, resources, policies, support on the left visible columns; newsletter, press, careers, trade program on the right visible columns).

**Bottom zone:** A **two-part horizontal bar** — far left: a row of social media icons; far right: a row of legal/policy text links + copyright notice. Both groups are baseline-aligned, creating a clean horizontal strip.

The footer uses **generous vertical spacing** between zones — it doesn't feel cramped.

---

## 6. Notable Layout Patterns

### Floating Modal / Popup
A **subscription popup** appears layered over the page content — it uses a **split-panel modal** design: the left half is a dark-toned image panel, the right half is a light panel with offer copy and a CTA button. The modal is **centered in the viewport** with a close (×) button in the top-right corner of the light panel. This split-panel modal echoes the site's own two-column editorial layout — it feels native to the design system rather than a generic lightbox.

### Full-Bleed Image Sections as Pacing Devices
The page uses full-bleed images not just as backgrounds but as **structural pacing elements** — they act as visual "chapter breaks" between product/content sections. The transition from light to full-bleed and back creates a strong spatial rhythm.

### Text-Over-Image (No Backing Cards)
Throughout the hero and editorial sections, text is placed **directly over photography** without any semi-transparent backing box or card. This is a confident, high-design choice that requires careful image selection and color contrast management.

### Overlapping Hierarchy via Z-axis
The header, announcement bar, and hero all exist on different Z-layers — the header floats above the hero image, and the modal floats above everything. This three-layer Z-axis structure (page → header → modal) is the primary depth mechanism on the page.

### Consistent Section Eyebrows
Every major section uses the same typographic pattern for labeling: **small, tightly letter-spaced uppercase text** as a visual signpost before the main headline. This creates a consistent scanning pattern for the eye as it moves down the page.
