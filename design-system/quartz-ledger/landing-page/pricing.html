Questions about the record.

Can I export my annotations if I cancel?

Yes. Your annotation data is yours. At any point — including after cancellation — you can export a complete JSON record of all annotations, resolutions, and metadata for every document you own. We do not hold your records.

Does the free Solo plan include compliance export?

PDF export with annotations is included. Structured compliance reports — the machine-readable export mapped to standards clauses — require Professional or higher. The distinction: PDF export is a document view. Compliance export is a structured record.

What counts as a "document"?

A document is any single imported file or Markdown paste. Versions of the same document count as one document. There is no restriction on document length or annotation density — only on the number of distinct documents on the Solo plan.

How does the standards taxonomy mapping work?

Margin ships with built-in clause hierarchies for ISO 27001, WCAG 2.2, and NIST SP 800-53. When you tag an annotation, you select from a searchable clause list. Custom schemas — your own taxonomy, a client's regulatory framework — can be imported as JSON on Professional and Team plans.
