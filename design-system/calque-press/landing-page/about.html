Institutional pilots live

Institutional analysts spend the majority of their research time not thinking — but reading. Not reading to understand, but reading to locate: finding the clause, the ratio, the disclosure change that determines whether an investment thesis holds. Pellucid was built to make that location work disappear entirely.

We started from a simple observation: the problem isn't that analysts lack intelligence. The problem is that the documents they work with are not designed to be queried. A 500-page offering memorandum is designed to be printed and signed, not interrogated. An EDGAR filing is designed for regulatory compliance, not comparative analysis. Pellucid rebuilds these documents — not as text, but as structured semantic objects — so that what they contain is accessible in the same way a database is accessible.

The critical constraint we set for ourselves from the beginning: Pellucid must not invent. Every answer it returns must be traceable to a specific passage in a specific document. This means the system cannot be used as a shortcut to a conclusion — only as a tool for reaching conclusions faster, with better evidence.

We work with a small number of institutional partners at a time. This is by design. Building document intelligence that earns the trust of analysts who are accountable for real capital decisions requires close collaboration, not scale. Our pilots are working partnerships, not product trials.

Security

Built for institutional data requirements.

Single-tenant deployment

Every Pellucid client operates in a fully isolated environment. Document corpora are never co-mingled across client accounts. There is no shared infrastructure layer between clients at the data or compute level.

Encryption at rest and in transit

All documents are encrypted at rest using AES-256. All data in transit is encrypted with TLS 1.3. Encryption keys are managed per-client and rotated on a configurable schedule.

Data residency options

Clients with jurisdictional requirements can specify data residency at the region level (EU, UK, or US). For clients with strict on-premise requirements, Pellucid can be deployed within the client's own infrastructure with no outbound data transfer.

Access audit log

Every query, every document access, every export is logged with user, timestamp, and document reference. Audit logs are available via API and can be exported to the client's own SIEM or compliance management platform.

Role-based access control

Access to document corpora and query capabilities is controlled at the role level. Administrators can restrict access to specific document sets by team, function, or individual user. SSO integration is supported via SAML 2.0 and OIDC.
