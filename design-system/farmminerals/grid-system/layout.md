# Brand Name Website - Layout System Brief

## 1. Overall Page Structure

The site follows a **storytelling scroll architecture** with approximately 10-12 major sections flowing vertically. The layout alternates between full-width immersive moments and structured content zones, creating a cinematic rhythm.

**Spatial flow pattern:**
- Dark-to-light gradient progression (dark primary color → light neutral)
- Alternating asymmetric splits (50/50, 40/60, 60/40)
- Breathing room between sections with generous vertical padding
- No rigid grid system—sections adapt fluidly to content needs

The overall impression is **cinematic and editorial**, prioritizing visual storytelling over dense information architecture.

## 2. Header/Navigation Layout

**Fixed header** (appears consistent across all views):
- Three-zone horizontal layout: `[MENU] ← → [Logo] ← → [CONTACT US]`
- Logo: Centered vertically and horizontally
- Menu button: Top-left corner, minimal icon + label
- Contact CTA: Top-right corner, text-only link
- Transparent/minimal background—floats over content
- Feels like 60-80px height, prioritizing screen real estate

**Visual hierarchy:** The header is intentionally understated, letting content dominate.

## 3. Hero Section

**Full-viewport immersive layout** with layered depth:

**Structure:**
- Left third: Large display headline ("Product Tagline") positioned mid-height
- Center-right: 3D product photography floating in space
- Right third: Secondary headline + description + CTA button positioned bottom-third
- Background: Dark brand color with soft-focused organic shapes creating depth planes

**Layering approach:**
- Background layer: Blurred organic shapes (suggesting industry-specific aesthetic)
- Middle layer: Sharp product render (product with embossed logo)
- Foreground layer: Typography
- Multiple z-index planes create **spatial depth**, not flat composition

**Proportions:**
- Headline: ~30% viewport width
- Product: ~25-30% viewport width  
- Right content: ~25% viewport width
- Negative space: ~40-50% of total canvas

The hero **doesn't follow a grid**—elements float with intentional asymmetry.

## 6. Notable Layout Patterns

### **Floating Elements & Layered Depth**
- Product imagery consistently **floats in space** with shadow/glow effects
- Multiple z-index planes in hero and product sections
- Background elements (organic shapes) create atmospheric depth

### **Asymmetric Splits**
- **No symmetric 50/50 layouts**—every split has intentional imbalance
- Weight shifts: 60/40, 40/60, 70/30
- Creates dynamic tension and guides eye movement

### **Photography as Structure**
- Full-bleed images aren't just decoration—they're **layout anchors**
- Photos bleed edges completely (no padding/margin)
- Text overlays photos with high contrast (white on dark, dark on light)

### **Diagonal Reading Paths**
- Content creates implied diagonals through positioning
- Top-left → bottom-right is dominant pattern
- Negative space distribution reinforces diagonal flow

### **Breathing Sections**
- Generous vertical padding between sections (~100-200px)
- Sections feel like **individual chapters**, not continuous scroll
- White space used as **punctuation**, not filler

### **Annotation Style Layout**
- Product sections use **side panels as annotations** to central image
- Horizontal lines connect panels to image, suggesting relationships
- Feels educational/editorial

### **Color as Spatial Indicator**
- Dark brand color = product/innovation zones
- Light neutral = data/information/transparency zones
- Color shifts signal **content mode changes**

### **Typographic Anchors**
- Large headlines (80-120px) serve as **section anchors**
- Positioned with intent: top-left, bottom-right, center
- Creates visual "stakes" in the layout ground

### **Card Systems**
- Cards maintain strict internal consistency (icon, headline, text)
- Card groups use equal widths and spacing
- Cards float on backgrounds with subtle shadows (not heavy borders)

### **No Fixed Grid**
- Layout adapts to content needs, not forced into 12-column grid
- Columns vary: 2-col, 3-col, asymmetric splits, triptychs
- **Content-first, grid-second** approach

---

## Summary

This layout system prioritizes **cinematic storytelling over rigid structure**. It uses asymmetric compositions, layered depth, full-bleed photography, and intentional negative space to create an editorial, almost magazine-like experience. The design feels **organic** while maintaining precision in spacing and hierarchy.

The key principle: **Every section is a designed moment**, not a templated block.
