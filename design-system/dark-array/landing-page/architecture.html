System Architecture

AXQ-1024 · Hardware Stack · Rev 2.1

SYSTEM STRATIFICATION

Four-Layer Hardware Stack

L1

Cryogenic Layer · 15 mK

Oxford Instruments Triton 500 dilution refrigerator customized for 1024-qubit QPU integration. 400 μW cooling power at 100 mK. Superconducting qubit chip mounted on oxygen-free copper cold finger. All qubit control lines attenuated, filtered, and thermalized at each temperature stage (4K, 800mK, 100mK, 20mK, 15mK).

L2

Qubit Layer · Superconducting Transmons

100,352 fixed-frequency transmon qubits on 300mm wafer. Tunable coupler architecture between all nearest-neighbor pairs. Qubit frequencies 4.8–5.4 GHz with 200 MHz spacing to prevent spectral crowding. Aluminum Josephson junctions fabricated via shadow evaporation in class-100 cleanroom.

L3

Control Layer · FPGA Real-Time

Custom FPGA control boards at room temperature drive all microwave and flux control lines. Each board manages 64 qubits. Cycle time: 1 μs including syndrome extraction, minimum-weight perfect matching decoding, and correction pulse generation. Total control stack latency from syndrome detection to correction application: 850 ns.

L4

Classical Interface Layer · API + SDK

OpenQASM 3.0 circuit submission via REST API. Python SDK with Qiskit and Cirq compatibility layers. Compiler transpiles logical circuits to native gate set in under 40ms. Job scheduling, queue management, and result retrieval via authenticated API endpoints with 256-bit encrypted transport.

CONTROL ELECTRONICS

FPGA Control Stack

Custom FPGA Boards

Xilinx Ultrascale+ FPGA-based control boards. 64 qubit channels per board × 1,567 boards. Direct DAC output at 12-bit, 2.4 GSPS for microwave pulse generation. Single-board power draw: 45W.

Real-Time Decoder

Minimum-weight perfect matching decoder implemented in FPGA logic. Processes 200,704 syndrome bits per cycle (2 per physical qubit). Total decode + correction latency: 700 ns from syndrome extraction to pulse output.

Timing Synchronization

GPS-disciplined 10 MHz reference clock distributed to all FPGA boards via low-skew network. Inter-board timing jitter: <10 ps RMS. Enables simultaneous gate operations across all 100K physical qubits with sub-nanosecond precision.
