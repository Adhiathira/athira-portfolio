PRODUCT DESIGNATION

AXQ-1024

The AXQ-1024 is the first commercially deployed quantum processor system to achieve fault-tolerant logical qubit operation at scale. It is not a research system with operational characteristics pending. It is a production platform with a defined SLA, documented API, and active user access program.

The system encodes 1,024 logical qubits in a surface code array of 100,352 physical qubits. Error syndromes are extracted and decoded in real time at the QPU operating temperature without warm-side latency.

QUANTUM ERROR CORRECTION

Surface Code Implementation

01

Distance-7 Surface Code

Each logical qubit is encoded in a 7×7 array of data qubits with ancilla qubits interleaved for stabilizer measurement. The distance-7 code tolerates any combination of up to 3 simultaneous physical qubit errors before the logical error rate increases. At current physical error rates of ~0.1%, this provides logical error rates below 10⁻¹² per gate.

02

Real-Time Decoding

FPGA-based minimum-weight perfect matching decoder runs at the QPU. Syndrome extraction, classical communication, and correction application complete within a single 1μs cycle. No warm-side latency.

03

Fault-Tolerant Gates

Logical Clifford gates via lattice surgery. T-gate injection via magic state distillation. Universal fault-tolerant gate set verified to 99.97% average fidelity across the full logical register.

04

Mid-Circuit Measurement

Non-destructive ancilla readout preserves data qubit coherence during syndrome extraction. Supports mid-circuit measurement for adaptive algorithms and quantum error mitigation protocols.

05

Leakage Suppression

Active leakage reduction units monitor and reset leaked states in transmon qubits. Leakage rate maintained below 0.01% per gate, extending effective T1 for deep circuits.

06

Crosstalk Calibration

Simultaneous randomized benchmarking across all qubit pairs characterizes two-qubit gate crosstalk. Automated compensation via Z-pulse shaping reduces parasitic ZZ coupling to below 1 kHz.
