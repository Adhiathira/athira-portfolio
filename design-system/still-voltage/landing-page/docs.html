Quick Start

Get your first 3D web experience live in under 10 minutes. This guide walks you through creating a scene, adding motion, previewing, and exporting to production-ready HTML.

1. Create a project

Open Volt Studio at app.voltstudio.io and click New Project. Give your project a name — this becomes the export filename prefix.

Tip

If you're coming from Figma, install the Volt Studio Figma Plugin first. It syncs your design tokens automatically so you skip the manual setup step.

  1. Choose your projection mode Select Isometric for a fixed-angle 3D look, or Perspective for a more natural camera. You can switch at any time — your scene adapts automatically.
  2. Set your canvas dimensions Volt defaults to 1440×900px. For a full-viewport hero, set width to 100vw and height to 100vh — the editor will show breakpoint markers.
  3. Import your design tokens Paste a CSS custom properties block or connect your Figma file. Volt maps your colors, type, and spacing tokens to the scene editor controls automatically.

2. Build your scene

The Scene Editor uses a node graph. Every element in your scene is a node — shapes, imported 3D objects, lights, and camera rigs all connect in the graph.

→ assets/docs-scene-node-graph.jpeg

Adding objects

Press A to open the Add Object panel. You can add primitive shapes (cube, sphere, cylinder, torus), import GLTF/OBJ files, or place a Figma frame as a flat 3D object.

Transform controls

Select any node and use the transform gizmo: G = grab/move, R = rotate, S = scale. Add an axis constraint: G + X constrains move to X axis.

3. Add motion

Open the Motion panel with M. The timeline shows a horizontal strip per node. Click a node's strip to add keyframes or choose from the preset library.

Note

The Motion System requires the Pro plan. On the Free plan, you can use basic CSS transitions, but the visual timeline and GSAP export are Pro features.

Using easing presets

Volt ships with the same easing curves used across top-tier design systems. The default is Material Standard — cubic-bezier(0.4, 0, 0.2, 1).

CSS 
/* Volt easing tokens — available as CSS custom properties */
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);   /* Material Standard */
--ease-decelerate: cubic-bezier(0.0, 0.0, 0.2, 1);  /* Enter / expand */
--ease-accelerate: cubic-bezier(0.4, 0, 1, 1);    /* Exit / collapse */
--ease-smooth: cubic-bezier(0.165, 0.84, 0.44, 1); /* Smooth entry */

Stagger choreography

Select multiple nodes and choose Stagger from the Motion presets. Set the stagger step — Volt defaults to 0.1s per element. The timeline shows all staggered keyframes offset as a visual cascade.

JavaScript (GSAP export) 
// Volt GSAP stagger export — generated automatically
gsap.from('#features-grid .card', {
  scrollTrigger: { trigger: '#features-grid', start: 'top 80%' },
  y: 40,
  opacity: 0,
  duration: 0.7,
  stagger: 0.1,
  ease: 'cubic-bezier(0.4, 0, 0.2, 1)'
});

4. Preview your experience

Press ⌘ P to open the live preview. The preview uses the identical WebGL render context as the exported output — what you see here is exactly what ships.

Important

Volt's preview always renders at your machine's native DPI. The export adds devicePixelRatio detection automatically for crisp renders on high-density displays.

Use the breakpoint toolbar to test responsive behavior. Volt shows 375px, 768px, 1024px, and 1440px by default — matching the four standard breakpoints in the export.

5. Export to production

Press ⌘ ⇧ E to open the Export panel. Choose your export target:

  • HTML + CSS Self-contained file. No runtime. Works in any browser. ~0.5kb overhead.
  • GSAP + ScrollTrigger Standard HTML + a small JavaScript file. Requires public GSAP CDN (free). ~2.3kb overhead.
  • Three.js Scene Full-fidelity 3D. Requires Three.js CDN. ~8kb overhead for the Volt scene loader.
HTML (GSAP export — drop-in) 
<!-- Drop the exported files anywhere in your project -->
<link rel="stylesheet" href="volt-scene.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js"></script>
<script src="volt-scene.js"></script>

<!-- Place the scene container in your HTML -->
<div id="volt-hero-scene" class="volt-scene" data-volt-scene="hero"></div>
