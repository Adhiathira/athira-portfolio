Process

From description
to artifact

01

Describe your intent

Write in plain language — "design me a mounting bracket for a 60mm fan with M3 holes at the corners" or "generate a two-layer PCB for an ATmega32U4 keyboard controller." No CAD knowledge required.

02

AI generates the artifact

Draftform parses your description, selects the appropriate output format, and generates a real engineering file — parametric geometry, trace routing, or dimensioned drawings. Not a mockup. A file you can manufacture.

03

The interface adapts to the artifact

Controls are generated alongside the output. An STL renders in a 3D canvas with mesh inspection tools. A PCB layout opens in a trace viewer with net selection. A DXF loads with dimension annotation overlays. Each artifact type has its own appropriate interface.

04

Iterate and export

Refine with follow-up prompts — "add a cable gutter along the right edge" or "reroute power traces away from the antenna region." Export when ready: .stl, .dxf, .kicad_pcb, Gerber. Direct to fabrication.

Capabilities

Three output formats.
One prompt.

Draftform understands the engineering context of your request and routes it to the right generation pipeline — solid geometry for mechanical parts, 2D linework for fabrication drawings, copper topology for electronics. The interface assembles itself around the result.

Explore artifacts
Format 01

STL — 3D Solid Geometry

Parametric mesh generation for mechanical components. Describe topology, constraints, and tolerances in plain language. Output is a watertight solid ready for FDM, SLA, or CNC.

Format 02

DXF — Fabrication Drawings

Dimensioned 2D drawings with annotation layers, title block, and tolerance callouts. Compatible with any CAD import or laser cutter workflow.

Format 03

PCB — Layout & Routing

Schematic-to-layout from component descriptions. Two-layer and four-layer support. Exports to KiCad and Gerber for immediate fab submission.
