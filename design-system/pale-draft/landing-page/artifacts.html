Output formats

Three artifact types.
Each manufacturable.

Draftform does not generate previews or mockups. Every output is a real engineering file — ready for a 3D printer, a laser cutter, or a PCB fabrication service. The format is determined by what you ask for.

Format 01 / Solid Geometry

STL — 3D solid geometry

Describe a mechanical part in plain language. Draftform generates a watertight solid mesh with the topology, constraints, and tolerances you specified. Output is a binary STL file ready for FDM or SLA printing, CNC machining, or import into any downstream CAD system. Complex geometry — lattice structures, organic surfaces, multi-body assemblies — is fully supported through natural language description.

  • Format Binary STL
  • Export .stl · .obj · .step
  • Geometry Watertight mesh, parametric
  • Use cases FDM · SLA · CNC · CAD import
Request access to generate STL
Format 02 / Fabrication Drawings

DXF — dimensioned fabrication drawings

Generate dimensioned 2D drawings from a part description or an existing 3D model. Draftform produces orthographic views — front, top, side — with dimension lines, tolerance annotations, and a title block populated with the metadata you specify. Output is standard DXF 2010, compatible with any CAD import or direct laser cutter workflow.

  • Format DXF 2010
  • Export .dxf · .dwg · .pdf
  • Views Front · Top · Side · Isometric
  • Use cases Laser cutter · CNC plasma · CAD import
Request access to generate DXF
Format 03 / PCB Layout

PCB — layout and routing

Describe the electronics you're designing — microcontroller, peripherals, power requirements, form factor constraints. Draftform generates a complete PCB layout with component placement, trace routing, copper pours, and design rule check. Two-layer and four-layer topologies are supported. Output files are directly submittable to a fabrication service.

  • Format KiCad 6 · Gerber RS-274X
  • Export .kicad_pcb · Gerber · drill files
  • Layers 2-layer · 4-layer
  • Validation DRC · netlist check · clearance verify
