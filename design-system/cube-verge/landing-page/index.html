The Platform

Every tool the
system requires.

Forma packages the complete design-to-build pipeline. From parametric constraints to BIM-ready export — each module is engineered to interoperate without friction.

01

Parametric Modeling

Define rules, not shapes. Encode dimensional logic that propagates across every module in the system — change one parameter, update everything.

02

Module Library

12,000+ certified prefab components across structural, envelope, MEP, and finish categories. Filter by load, climate zone, and regulatory standard.

03

Constraint Engine

Hard constraints enforce code compliance. Soft constraints guide design intent. The engine resolves conflicts before they reach fabrication.

04

Site Analysis

Topographic data, solar exposure, wind loads, and zoning overlays — all resolved against your module system before a single element is placed.

05

BIM Export

IFC, Revit, and STEP outputs with full LOD 400 geometry. Every module carries embedded metadata — cost codes, spec sheets, lead times.

06

Collaboration

Shared model state across teams. Role-based access for architects, engineers, and contractors. Version-controlled design history with diff views.

Assembly Principle

Base module.
Infinite system.

Forma builds from the ground up. Every project starts with a single validated module — then the system assembles upward, outward, and across contexts. No custom solutions. No one-offs.

The assembly principle means every module decision is structural. Change a base component and the system recalculates load paths, spatial arrangements, and fabrication schedules in real time.
