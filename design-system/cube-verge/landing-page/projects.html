How Forma Builds

Every Forma project runs the same four-phase process. Constraints in, fabrication files out. No variation in rigor — only in parameters.

01

Analysis

Site geometry, program brief, and structural constraints are ingested into the parametric model. Ground conditions, local code overlays, and supply-chain adjacency are weighted before a single module is generated.

Site Survey Program Brief Code Overlay Constraint Mapping
02

Parametric Generation

The constraint set drives the module generation engine. Forma outputs a ranked configuration matrix — typically 6–12 candidate layouts — scored against cost, logistics, and structural efficiency. Client selects; Forma locks.

Module Configuration Structural Scoring Cost Modeling Layout Matrix
03

Documentation

Locked configuration generates full shop drawing sets, structural calculation packages, BIM export, and permitting submissions — all derived from the same parametric source. No coordination errors between disciplines.

Shop Drawings Structural Calcs BIM Export Permit Package
04

Delivery

CNC-ready fabrication files route directly to certified manufacturing partners. Forma coordinates logistics sequencing, site assembly schedules, and structural sign-off. Typical on-site assembly: 8–22 days.

Fabrication Files Logistics Sequencing Site Coordination Assembly Sign-Off
