Our Approach

FEA-backed.
Not estimated.

Torq's simulation engine runs finite element analysis on a per-cell basis. Every threshold value is derived from the actual geometry of the material — not from regression tables or approximated lookup curves.

Step 01

Geometry Ingestion & Mesh Generation

Torq accepts material specifications in standard formats: ASTM D3039 tensile data sheets, SEM cross-section exports, and CAD-derived material geometry files (.step, .iges). On ingest, the engine auto-generates an adaptive mesh — finer at stress concentrations, coarser in homogeneous regions — without manual tuning.

The mesh generator resolves down to 5-micron cell size for carbon fiber reinforced composites, matching the resolution required for accurate inter-laminar shear failure prediction. For metal alloys, cell size adapts automatically to grain boundary data embedded in the material specification.

→ assets/method-mesh-generation.jpeg
Step 02

Per-Cell Finite Element Analysis

Each cell in the mesh is treated as an independent finite element with its own material property tensor. Torq solves the system of equations governing stress, strain, and deformation using a sparse direct solver optimized for composite anisotropy — not a general-purpose FEA kernel.

Simulation resolves at 40ms per node under standard load conditions. For multi-axis loading scenarios (combined tensile + shear), the engine runs load case superposition in a single pipeline pass. No re-meshing between load cases.

Step 03

S-N Curve Modeling & Fatigue Forecasting

Torq generates S-N curves (stress vs. cycles to failure) from the FEA output using a modified Basquin law, fitted to the material's actual microstructure rather than to population-average empirical data. The curve reflects the specific fiber architecture, void distribution, and resin system of the ingested material.

Fatigue forecasts are probabilistic: Torq outputs a 90th-percentile confidence band alongside the median prediction, enabling engineers to set conservative design thresholds without arbitrary safety factors.

Step 04

Compliance-Ready Output Generation

Every simulation run automatically generates structured output mapped to the relevant test standard. Torq supports the following standards for automatic output generation:

ISO 6892
Metallic materials — tensile testing at ambient temperature
ASTM E8
Standard test methods for tension testing of metallic materials
EN 10002
Tensile testing — method of test at ambient temperature
ASTM D3039
Tensile properties of polymer matrix composite materials
ISO 14129
In-plane shear stress/shear strain response of CFRP
ASTM E466
Conducting force-controlled constant amplitude axial fatigue tests

Documents are exported as structured PDF with embedded raw data tables, suitable for direct submission to accreditation bodies without manual data transfer or re-formatting.
