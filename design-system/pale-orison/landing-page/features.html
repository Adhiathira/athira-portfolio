The workspace

Built for
careful thinking.

Four tools that work together. Each one earns its place in the workflow.

01

Thread-linked annotation

An annotation is not a comment. In Parable, every note carries a type — claim, evidence, objection, unresolved question. It knows what precedes it and what responds to it. The result is a margin that thinks, not just records.

Select any passage. Add your note. Tag it. Link it to a prior annotation, a different document, or an argument branch. The thread builds itself.

02

Argument structure view

Claims, evidence, and counterarguments rendered as a navigable tree. Collapse a branch and see what stands without it. Expand a sub-claim and read every source it rests on.

Not a mind map. Not a corkboard. An argument structure — the form your thinking already has, made visible.

Request access
→ assets/feature-argument-map.jpeg
03

Shared reading rooms

Invite a colleague into a document. Their annotations appear in a distinct register — different weight, different margin column. You read in the same document, in the same moment, with full visibility into their work. Or not. Visibility is per-permission, per-reader.

A reading room is not a chat thread. It is a shared act of attention.

→ assets/feature-reading-room.jpeg
04

Export to brief
or memo.

When the argument is ready, export it. Your annotation tree becomes a structured outline — claims as headings, evidence as body, counterarguments as footnotes. The form follows the logic you built, not a template.

Word, PDF, Markdown. Choose the format your firm uses.
