What Parable does

01

Thread-linked annotation

Connect notes across documents, pages, and sources. Each annotation knows what it is responding to — and what responds to it.

The annotation layer

Dense text,
clear margin.

Parable keeps the document intact. Your annotations live beside it — never inside it. Toggle the margin to full screen when the argument needs space. Return to reading when it doesn't.

The workflow

From source
to argument.

  1. 01

    Import any document

    PDF, Word, or pasted text. Parable preserves the original typographic structure — footnotes, headings, case citations.

  2. 02

    Annotate with precision

    Select any text range. Add a note, a claim tag, an evidence marker, or a counterpoint flag. Each annotation carries its type.

  3. 03

    Build the argument map

    Connect annotations into a structured tree. See which claims are supported, which are contested, which are unresolved.

  4. 04

    Export to brief or memo

    One click to structured outline. Your argument map becomes a draft. Your team sees only what's been resolved.
