## 6. Notable Layout Patterns

### Sticky Navigation
The nav bar persists at the top of the viewport throughout the full scroll. It maintains a light/translucent background, ensuring legibility against both light and dark sections.

### Section-Overlap / Bleeding Cards
The hero's three-card strip bleeds downward past the section boundary — the bottom of the cards visually "sits on" the next section's light surface. This is a deliberate device to prevent hard breaks and suggest continuity of the product story.

### Alternating Full-Bleed vs. Contained Width
The page rhythmically alternates between: full-viewport-width sections (logo bar, testimonials, dark promo) and centered, max-width content containers (~1200–1400px). This creates a **breathing pattern** — expansion, contraction, expansion — that keeps the scroll feeling dynamic without overwhelming.

### Floating UI Mockups
Multiple sections use **product UI screenshots as floating objects** — not constrained to image containers, but positioned as if hovering in space with drop shadows. In the feature matrix section, the right-side UI panel extends slightly beyond its column boundary, breaking the rigid grid deliberately.

### Layered Z-Depth in the Dark Section
The dark section uses a stacked browser frame composition where multiple content screenshots appear at different depths and angles, creating a subtle **parallax z-axis** impression even in static form.

### Cookie Banner
A floating consent dialog is pinned to the bottom-left corner — fixed position, light card with shadow, visible across multiple scroll positions. Notable that it does not obscure the primary content column.
