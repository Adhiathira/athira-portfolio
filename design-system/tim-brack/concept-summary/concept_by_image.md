# Tim Brack — Concept by Image

## Brand Premise

A creative portfolio site constructed around a single architectural premise: typography at extreme scale is not a headline device but a compositional object that occupies space, overlaps images, and defines the page's visual structure. The site belongs to the tradition of brutalist web design — minimal color, zero ornamentation, no decorative UI — but executes it through editorial intelligence rather than willful austerity. Every layout decision exists to serve the work, not to announce a design philosophy.

## Color Architecture

The palette is rigorously monochromatic: white page backgrounds for all primary content zones, near-black body text (`#000000`), gray for secondary and metadata text (`#999999`), and a dark gray or charcoal for the terminal CTA section — the only background color change on the page. Heading text in tokens is white (`#ffffff`), which corresponds to the large white titles in the dark CTA footer section. There is no accent color, no chromatic variation, no gradient. The system achieves all its hierarchy and differentiation through the contrast and spatial relationship of these four tonal values.

## Typography System

Two typefaces, extreme role separation. Grotesk-Bold (proprietary grotesque sans) is the primary display face — used for titles at a scale that Gemini's analysis identified at over 100px, with tokens confirming h1 at 206px. At this scale, each letterform becomes architectural: the title of a project occupies the same visual territory as the image it labels, and the two elements exist in deliberate compositional tension rather than hierarchy. Times (serif, system typeface) is used for body text at 16px — an intentionally humble and unseated choice that creates a maximum contrast between the display world (206px grotesque) and the informational world (16px Times). The design uses typeface voice to encode context: grotesque says image, Times says reading.

## Spatial System

Four distinct zones. The full-screen typographic intro section occupies the opening viewport: a multi-line block of Grotesk-Bold text at large scale, left-aligned, no other elements — typography as introduction, not headline over background. The main showcase sections repeat: each module combines a large rectangular media element with a massive title typeset directly over it, aligned to bleed partially off the image's edges, plus small corner metadata labels (top-left and top-right positions). These modules alternate the media's horizontal alignment (image left, then image right) to create rhythm without changing the pattern. The dark CTA section closes the page with centered large type on a dark ground — an inversion that announces the end. Detail pages use a back link, a paragraph of body text, and a vertically stacked media gallery with no compositional complexity.

## Photography and Editorial Voice

Photography is art-directed specifically for this layout: each image must provide a "text-safe zone" — a region of sufficient contrast or negative space where the overlapping title can be read. This is not photography chosen to look beautiful in a grid; it is photography chosen to function as a layer in a typographic composition. All images are rectangular with sharp 90° corners, presented without frames or containers, scaled to occupy significant portions of their section width. On detail pages, images are presented at full width in a simple vertical stack — the compositional restraint of the main page gives way to direct, focused presentation when the work needs to be read rather than discovered.

## Navigation and Wayfinding

There is no traditional persistent navigation bar. The sole global navigation element is a small two-line text element in the top-right corner of the main page that scrolls away with the content — not sticky. On detail pages, a single "back" link in the top-left corner provides the only navigation chrome. This is a deliberate UX commitment to content immersion: the absence of a fixed nav eliminates the visual frame that would remind the user they are browsing a website, making the scroll experience more focused and less mediated. Navigation is contextual and minimal — built into the content rather than imposed over it.

## Overall Design Character

The site's formal argument is that the relationship between a title and an image is more interesting when they share the same plane — when the text does not sit below or adjacent to the image, but over it, competing with and complementing it. At 206px, a project title is not a label; it is a graphic element of equivalent visual weight to the photograph it names. This compositional strategy, paired with a monochromatic palette and zero decorative UI, produces a site that feels genuinely authored rather than assembled. The brutalist tendency is present but subordinated to editorial intelligence: the restraint is in service of the work, not a statement about restraint itself.
