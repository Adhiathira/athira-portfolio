## Notable Layout Patterns

- **Alternating section backgrounds** (accent ↔ dark charcoal) are the primary pacing device — used consistently to break the page into digestible chapters
- **Rounded-corner section panels** appear on accent sections (top corners rounded), creating the "floating card landing on dark" effect — a deliberate layering trick that adds depth without true 3D
- **Repeating logo tile strip** at the hero bottom is a unique branded divider — not a standard HR or gradient, but a tiled brand element used as spatial punctuation
- **Inline two-color headings** (accent + white within the same headline) appear in at least two sections — a typographic pattern that creates emphasis hierarchy within a single line
- **Mascot/illustration columns** appear twice (brand story panel, community section) — large accent-colored illustrations used as structural layout elements, not decorative flourishes
