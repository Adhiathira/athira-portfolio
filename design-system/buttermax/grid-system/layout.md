# Brand Name — Layout Brief

## Overall Page Structure

Single-page composition visible in this viewport. The page uses a full-bleed, edge-to-edge canvas approach with no gutters or container constraints at the outermost level. The visible section is essentially one dramatic hero occupying the entire viewport height, with a thin cookie consent bar anchored to the bottom edge.

---

## Header / Navigation

**Sparse three-zone bar** sitting flush against the top edge with no visible background or border — it floats transparently over the hero content.

- **Left zone:** A single icon/glyph — functions as logo or close/menu trigger
- **Center zone:** A stylized logo mark — strictly symmetrical centerpiece
- **Right zone:** Three pill-shaped navigation links — each with a visible stroke border and no fill, creating outlined button badges rather than plain text links

The nav has generous lateral padding. All three zones sit on the same invisible baseline. The logo dominates the center visually, while the pill nav items introduce the only geometric border element in an otherwise borderless space.

---

## Hero Section

**Full-viewport, full-bleed layout** — the primary color field extends to all four edges with no margin or padding visible.

**Three overlapping layers create the composition:**

1. **Large-scale display type** — Brand Name rendered at an extreme scale, bleeding off the left and right edges. The letterforms are so oversized they function more as texture and background pattern than readable headline. This creates a letterform-as-environment effect. The type sits behind the central product image.

2. **Product object** — A 3D-rendered product placed dead center, tilted at roughly 15° clockwise. It overlaps the headline text, creating clear foreground depth. The object is approximately 45% of the viewport height and commands visual gravity through its realistic shadow, material detail, and central positioning.

3. **Handwritten script accent** — A loose, brush-stroke mark appears in the upper right quadrant, layered above the display type but behind or at the same depth as the product. It introduces organic contrast against the geometric type.

**Subtitle / tagline:** A single line of small uppercase tracking — a short brand positioning statement — sits roughly at the vertical midpoint, left-aligned, acting as a quiet anchor beneath the headline's first line.

**Spatial rhythm:** The composition is intentionally chaotic at the macro scale (oversized bleeding type, tilted object, handwritten mark) but anchored by the single centered product — controlled chaos with a strong focal point.

---

## Cookie Bar (Bottom Strip)

A **full-width, low-height dark bar** pinned to the bottom of the viewport. It acts as a strong color contrast band against the primary color field above.

- **Left zone:** Small-print legal/consent copy in light text, left-aligned with comfortable left padding
- **Right zone:** Two pill-outlined buttons — Primary CTA and Secondary CTA — mirroring the nav pill style from the header, creating a design language echo

The bar has the visual weight of a footer but functions as a persistent overlay. Its darkness grounds the page and frames the hero from below.

---

## Notable Layout Patterns

| Pattern | Description |
|---|---|
| **Full-bleed color field** | Primary color extends edge-to-edge, no container or max-width visible |
| **Typographic scale as spatial element** | Headline type functions as background texture at display scale |
| **Layered z-depth** | Three distinct depth planes: type → product → UI chrome |
| **Floating transparent nav** | Header has no background, floats over hero content |
| **Pill badge UI language** | Both nav links and cookie buttons use the same outlined pill shape — a consistent micro-pattern |
| **Object bleed** | The tilted product image likely extends slightly beyond its natural bounds, reinforcing the off-grid energy |
| **Color contrast as section break** | The dark cookie bar creates a hard horizon line — no need for a traditional footer divider |

---

## Design Voice (Layout)

This is a **maximalist, confidence-first layout** — it prioritizes visual drama over legibility comfort. The hierarchy is implicit (object → type → tagline) rather than conventional (headline → subhead → body). The page trusts the viewer to orient themselves in a dense composition rather than guiding them step by step. The restraint lives in the nav and the cookie bar — both are minimal and well-spaced — which makes the hero chaos feel intentional rather than accidental.
