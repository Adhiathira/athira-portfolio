The Core Principle

Every output is traceable
to the data that produced it.

Strata's analysis pipeline is designed around a single constraint: every number in a report must be derivable from first principles, starting from the uploaded survey files. No intermediate steps are hidden, no assumptions are unrecorded. If a reviewer questions a bearing capacity estimate, they can trace it back through the load-ground model, through the interpolation grid, to the specific CPT test points that informed that node.

Standards Compliance

Built to the standards
your review board requires.

EN 1997

Eurocode 7 — Geotechnical Design

ULS and SLS verifications using characteristic value derivation per Annex B. Partial factors applied per the National Annex of the project jurisdiction.

ASTM D

ASTM — Geotechnical Standards

Soil classification per ASTM D 2487 (USCS). CPT interpretation per D 3441. Pile load testing per D 1143. All output parameters reference the applicable ASTM designation.

BS 5930

Code of Practice for Ground Investigations

Site investigation reporting structured to BS 5930:2015+A1:2020, including factual and interpretative reporting phases with defined data quality categories.

ISO 22282

Geohydraulic Testing

Permeability and hydraulic testing data processed per ISO 22282-1 through 22282-6. Piezometric data ingested and interpreted to ISO 22282-4 compliance.

IFC 4.3

BIM Integration Standard

Model exports in IFC 4.3 format, including IfcGeotechnicalElement entities for direct import into Revit, Archicad, and OpenBIM-compatible infrastructure platforms.

ISO 31000

Risk Management Framework

Risk scoring and prioritisation matrices structured to ISO 31000:2018, with site hazard classifications that map directly to project risk registers.

Validation

Calibrated against
real project outcomes.

The Strata interpolation engine has been validated against back-analysis data from 140 completed infrastructure projects across eight European countries — comparing modelled predictions to observed settlement, bearing failure, and groundwater behaviour during and after construction. Calibration is ongoing and site-type specific: offshore foundations, road embankments, and deep basement excavations each use separate validation datasets.
