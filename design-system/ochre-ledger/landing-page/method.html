How it works

From practice library to construction issue — four stages.

Burnham's workflow follows the architecture of a real project — not a generic document management system repurposed for specifications.

→ assets/method-1.jpeg

Stage 01

Build your practice library.

The library is the foundation. Every clause your practice will ever write lives here — organised by NBS section, RIBA stage, building typology, or your own taxonomy. Once it exists, every new project draws from it.

  • Import from NBS, RIBA, or your existing Word specifications
  • Organise by section, typology, or custom taxonomy
  • Share across the whole practice — no per-seat licensing
  • Version every clause independently from its project instances
→ assets/method-2.jpeg

Stage 02

Build a project specification.

Open a project, select the library clauses that apply, and customise them — adding specific material standards, performance requirements, and supplier preferences. Drawing cross-references attach to the relevant clauses as your CAD evolves.

  • Pull clauses from the library in bulk or one at a time
  • Customise without breaking the library master
  • Attach manufacturer data sheets to individual clauses
  • Link drawing numbers — see which clauses reference each sheet
→ assets/method-3.jpeg

Stage 03

Issue and respond.

Generate formal issue packages for tender or construction. Contractors receive structured PDFs with linked data sheets and clause references. Substitution requests come back into Burnham as logged records — not emails.

  • Generate issue packages with one click
  • Contractors respond directly into Burnham via a shared portal
  • Every substitution request is logged, reviewed, and decided in the system
  • Full audit trail from first issue to final approval
→ assets/method-4.jpeg

Stage 04

Close the loop.

At handover, export the as-built specification — including all approved substitutions, updated data sheets, and a complete revision history. The building record your client needs for the life of the building.

  • As-built export includes all approved changes
  • O&M manual integration — specification clauses map to building components
  • Everything the FM team needs in a format they can search
