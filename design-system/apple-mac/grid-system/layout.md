# Product Category Page — Layout Brief

## 1. Overall Page Structure

The page is a long-form product category page with approximately 10–12 distinct sections. The flow moves from navigation → category hero → horizontal product carousel → product grid with filter → value proposition cards → editorial feature tiles → interactive decision tool → cross-sell panels → ecosystem promotion → footer. The rhythm alternates between white-background sections and light gray sections, creating a clean breathing cadence that separates content clusters without hard dividers.

---

## 2. Header / Navigation

The global nav is a full-width, centered bar with the brand logo anchored center-left and product categories spaced evenly across a single horizontal row. It sits at a fixed, slim height — roughly 44px — and feels weightless. Search and cart icons are right-aligned. The nav uses no visible dividers; white space alone creates the separation between items.

Directly below the global nav is a thin promotional banner — a single centered line of text with an inline CTA link. It spans the full width at reduced font size, acting as a quiet informational strip without competing for attention.

---

## 3. Hero / Page Header Section

This is not a traditional hero. Instead of a full-bleed image or cinematic takeover, it uses a stark typographic hero: the category name in an oversized, heavyweight serif-adjacent sans-serif, positioned flush-left with generous top and bottom padding. Background is pure white. No imagery. The hierarchy is immediate — the category name dominates, occupying roughly 25–30% of the viewport width while the rest of the space breathes empty.

Immediately below this typographic anchor is a **horizontal product carousel** — product thumbnails with labels and "New" badges, arranged in a single scrollable row. Items are evenly spaced with consistent margins, and a right-arrow affordance hints at overflow content. The carousel sits against white and feels like a persistent product index rather than a decorative element.

---

## 4. Content Sections Below the Hero

### Section: "Explore the Lineup" — Filter + Product Grid

Background shifts to light gray. A section label uses the same heavy weight as the hero type, left-aligned. Below it sits a horizontal pill-based filter row (e.g., "All products / Category A / Category B / Category C") with the active state shown as a filled dark pill. This filter control is compact and sits close to the section label.

The product cards below form a **multi-column grid** — approximately 4 columns at desktop width. Each card is a white rounded rectangle with generous internal padding. Inside each card: color swatches at top, product name in medium weight, short descriptor in lighter weight, price/financing line, and two CTAs (primary filled button + secondary text link). The cards have consistent height with slight vertical rhythm variation due to tagline length. The grid feels structured but not rigid — the equal column widths create clear visual alignment.

---

### Section: "Why [Brand] is the Best Place to Buy" — Value Props

Section label is large, heavy, left-aligned, spanning roughly 40% of the page width. A "Shop [Category] >" text link sits right-aligned on the same baseline — a classic two-column header with label left and action right.

Below: a **horizontal scrolling card row** — four equal-width cards, white rounded rectangles on the gray background. Each card has a category label in small caps or reduced weight at top, followed by a bolded headline, then body text. No imagery in these cards — purely typographic. The layout communicates utility and trust rather than aspiration.

---

### Section: "Get to Know [Product]" — Editorial Feature Tiles

A **4-across asymmetric tile grid**. The leftmost two tiles are tall, dark-background cards with product photography occupying most of the tile. White text overlays sit in the bottom-left of each tile. The rightmost two tiles are lighter in weight — white/gray background with UI screenshots sitting below short-form copy, creating a lighter visual contrast. All four tiles share the same top alignment and approximate height.

Below this grid, the same 4-tile pattern continues with product feature expansions, but the carousel is shown mid-scroll — a right arrow visible confirms overflow content.

---

### Section: "Help Me Choose" — Interactive Decision Tool

A **single full-width rounded card** (white on white page, visually distinguished by its gray background fill) with approximately 40/60 column split. Left side: short-form copy ("Answer a few questions to find the best [Product] for you.") plus a single primary CTA button. Right side: an editorial illustration of key products — overlapping product images arranged in a loose, slightly perspectival stack. The illustration bleeds toward the top edge of the card. Layout feels like a contained, self-sufficient module.

---

### Section: "Switch to [Brand]" — Two-Column Feature Panel

A **50/50 split two-column layout** inside a light gray container. Left panel: centered copy (headline, body, text link CTA) above a lifestyle product photo. Right panel: centered copy with a product UI screenshot composition. Both panels share equal width and vertical padding, creating visual symmetry. The section header sits outside and above the two-column container, full-width.

### Section: "Product Essentials" — Two-Column Accessory + Cross-Sells

Another **50/50 split** with white rounded-rectangle cards. Left: accessories section with a 3×2 product image grid and a text link. Right: featured product with a large image and secondary CTA. Products are shown on white with no background — floating, clean. Both panels sit on a gray page background.

### Section: "Unlock the [Brand] Ecosystem" — Ecosystem CTA

Section label in large heavy type left-aligned, with a "Learn how [Brand] products work better together >" link right-aligned. This is a header row only — the actual content is partially visible, suggesting another card or panel below.

### Section: "Product and Companion Devices" — Accordion Feature Section

A **two-column layout with 40/60 proportions**. Left column: body copy with expandable accordion rows for companion product pairings — each row is a thin divider line with a label and a down-chevron icon. Right column: a large lifestyle screenshot showing the primary product and a companion device in use together, roughly 60% of the section width. This section uses visual weight contrast effectively — dense text list on the left, single dominant image on the right.

---

### Section: Legal / Footnotes

Small-type disclaimer paragraphs, full-width, centered in a constrained max-width column. These are visually recessive — reduced font size, normal weight. A breadcrumb row sits above the footnotes, acting as a section divider.

---

## 5. Footer

A **5-column link footer** on a light gray background. Column headers are bolded (e.g., Shop / Account / Services / Store / For Business / Values). Sub-items are non-bold links at smaller size. The footer has a second tier of columns below (For Education / For Healthcare / For Government / About Company) maintaining the same multi-column grid structure.

A final strip at the very bottom: a single line with store locator text links, followed by the copyright line and utility links (Privacy Policy / Terms / Legal / Site Map), right-aligned locale selector.

---

## 6. Notable Layout Patterns

- **Alternating white/gray sections** create spatial rhythm without explicit dividers — the page breathes in consistent beats
- **Full-width constrained content** — most content sits within a centered max-width column (~980–1200px), never touching viewport edges, which gives the page its airy margin proportions
- **Consistent rounded-rectangle cards** used across every content section create visual cohesion despite varied content types
- **Typography as structure** — section headers are large, heavy, and left-aligned consistently, making them function as visual anchors rather than decorative type
- **Left label / right action** header pattern repeats across multiple sections (section title left, "Shop [Category] >" right), establishing a reliable navigational rhythm
- **Horizontal carousels** for product rows preserve vertical compactness while implying depth of catalog
- **Editorial image bleeds** inside constrained cards (illustration cropped at card edge) add visual energy without breaking the grid
