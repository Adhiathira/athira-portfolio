Features

The three systems at the heart of Quire's compositional approach.

01

Compositional Intelligence

Quire reads your content structure — heading hierarchy, caption density, column count — and proposes grid configurations that serve the material rather than imposing a template. The system does not automate layout. It surfaces the grid options most likely to produce optically correct relationships between elements, then steps back.

The intelligence is editorial, not algorithmic. It draws on a library of layout decisions made by type directors at major publishing houses over decades — not training data, but structured knowledge encoded as design rules.

Variable Type Control

Optical size correction at every scale. Quire adjusts tracking, spacing, and weight automatically as type scales from caption to display — the same intelligence a type director applies manually, encoded as a responsive system. Fine-tune every parameter or accept the system's recommendations.

Variable font support is native. Axis ranges are exposed directly in the composition UI — no plugin, no conversion step, no workaround.

03

Grid as Structure

Build modular grids, baseline grids, column-based systems, or hybrid structures. Every grid configuration exports to CSS custom properties, Adobe InDesign settings, or Figma design tokens — the grid travels with the project across every tool in the workflow.

Quire treats the grid as a first-class design element, not an afterthought. Grid configurations are saved, versioned, and applied across document families with a single action.
