# Brand Name — Layout Brief

---

## 1. Overall Page Structure

The page is composed of roughly **8–9 distinct sections** flowing top to bottom. The overall rhythm alternates between high-impact, full-bleed visual moments and restrained, white-space-heavy content sections. This creates a strong push-pull between immersion and legibility — the page breathes between intense and airy zones.

Flow summary:
1. Full-bleed hero (viewport-height, light gradient background)
2. Manifesto / editorial text + 2×2 feature grid
3. Split-panel services showcase (dark + image + colored panel)
4. Popular items (asymmetric image + list grid)
5. Split dark section (app mockup + body copy)
6. "Experience" editorial header + feature grid
7. Full-bleed interior image carousel
8. CTA pre-footer (gradient fade)
9. Dark footer (two-part: navigation block + legal block)

---

## 2. Header / Navigation

The nav sits **transparently over the hero**, floating at the very top of the page. It has no visible background bar — it reads as pure overlay against the background.

- **Left:** completely empty (no logo in the nav bar itself — the wordmark lives in the hero)
- **Center-right:** three text links ("Solution A", "About us", "Contact") spaced with generous gaps, rendered in small, lightweight type
- **Far right:** a filled dark circle with a hamburger/menu icon — acts as the sole visual anchor of the nav

The nav has minimal visual weight — it defers entirely to the hero content below it.

---

## 3. Hero Section

**Full-bleed, viewport-height.** The hero is the most compositionally ambitious section on the page.

- The background is a **soft light gradient** — fading to near-white at the bottom
- The **brand wordmark** is set at extreme scale (roughly 60–70% of the viewport width), bleeding off both left and top edges — this is not a logo, it's a typographic texture
- A **trademark symbol** is displayed as a large outlined circle, floating to the upper-right of the wordmark at medium size — it functions as a graphic element as much as a legal mark
- A **3D rendered hero object** is positioned center-stage, overlapping the large wordmark behind it — the object casts no shadow but reads as floating in open space
- **Bottom-left:** a tagline in bold, small type
- **Bottom-right:** two pill-shaped CTA buttons ("Primary CTA" / "Secondary CTA") in dark, side by side
- **Center-right (mid-height):** a secondary headline block — "Brand Proposition" — in large bold serif-adjacent type, positioned at roughly 55% from the left edge

The hero uses **three overlapping z-layers**: background gradient → oversized wordmark → floating object + headline. Nothing is boxed. Elements float freely against the gradient field.

---

## 4. Content Sections

### Section 2 — Manifesto + Feature Grid

A **high white-space editorial section**. The top portion is dominated by a single statement in very large, heavy type — roughly 4 lines, set at ~80% viewport width, aligned to the right half of the page (the left ~40% is empty). This creates a strong asymmetric tension.

Below the large statement, the layout switches to a **2×2 feature grid**. Each cell is separated by a thin horizontal rule at the top. The grid occupies the right ~60% of the section width, leaving the left side again empty — maintaining the same asymmetric column logic as the headline above. Each cell contains:
- A bold feature title (small-medium)
- A short body paragraph in gray, lighter weight

Spacing between rows is generous. The grid reads as a quiet data table, not a card layout.

---

### Section 3 — Services (Split Tripartite Panel)

One of the most visually distinctive sections. The full viewport width is divided into **three equal vertical panels**, edge to edge with no gaps:

- **Panel 1 (left):** Dark background. Contains a section label ("Services") in large light type at top-left, and a short subheading + Action Button at bottom-left. The panel is mostly negative space — deliberate emptiness.
- **Panel 2 (center):** A **full-bleed photograph** filling its column completely top to bottom with no frame or border. The label "Service A" appears at the bottom-left in light type over the image.
- **Panel 3 (right):** A warm accent-color background. An animated **dashed arc line** traces a path curve from upper-right toward lower-left, with a small icon following the path. The label "Service B" appears at the bottom-left in light type. A small dot marker is placed near the bottom of the arc path.

This section uses **full-bleed color blocking** — the panels have equal weight and form a triptych.

---

### Section 4 — Featured Items

A two-column asymmetric layout on a light background:

- **Left (~45% width):** A large feature photograph with rounded bottom-right corner — the only image with a visible border radius on the page. Slightly cropped at the edges.
- **Right (~55% width):** A **2×2 list grid**. Each cell contains a primary label in bold + secondary code in parentheses (normal weight), a category name in light gray below, and a thin bottom border rule. Four items displayed.

The right column has no background treatment — pure light, relying entirely on typography and hairline rules for structure.

---

### Section 5 — Product / Feature Demo (Dark Split)

A 50/50 split section on a very dark background:

- **Left half:** A hand holding a device displaying the product interface — the image fills the left column completely, cropped at top and bottom
- **Right half:** Empty dark space in the upper portion, with a body copy block appearing in the lower-right quadrant in light text. The text is notably small relative to the section height — it anchors at the bottom-right.

This creates a **dramatic imbalance**: the left is fully occupied, the right is mostly void. The text feels almost hidden — discovered rather than announced.

---

### Section 6 — Experience Feature Grid

Opens with a **typographic moment**: a key brand word at enormous scale, cropped at the top (letters cut off), spanning the full viewport width. This is a section transition device as much as a headline — you encounter it while scrolling before you read it.

Below, the layout splits into two columns:
- **Left (~30% width):** A block of body copy in normal weight — brand philosophy text. Below it, bold callouts for key offerings. Toward the bottom, a "Contact us" pill button.
- **Right (~60% width):** A **2×2 icon + label + description card grid**. Each card has:
  - A dashed-border square icon container (thin line, no fill)
  - A bold feature title
  - A short body paragraph

The icon style is deliberately minimal/wireframe — maintaining a clinical, modern aesthetic.

---

### Section 7 — Interior Image Carousel

A **full-bleed, edge-to-edge photograph** of a product or space interior. The image occupies nearly the full viewport height. No frame, no padding.

In the lower-right corner, a minimal **slide counter** — left/right arrow icons flanking "1/6" in light type — is the only UI element. The carousel control is ghosted over the image with no background box.

---

### Section 8 — CTA Pre-Footer

A centered text block on a light/gradient background (accent color fading in from the top). Layout is simple:

- Small gray subheadline above
- Very large dark CTA headline ("Primary CTA") in extra-bold condensed type
- The gradient backdrop creates a visual echo of the hero — framing this as a bookend moment

---

## 5. Footer

The footer is split into **two distinct horizontal bands**, both on a dark background:

**Upper footer band:**
- Far-left: brand wordmark (light, compact)
- Below logo: "Follow us" label + three circular social icon buttons (Platform A, Platform B, Platform C) — outline style circles with icons centered
- Center-right: **Three columns of navigation links** — "Service A", "Service B", "Service C" — each with sparse sub-links below in muted gray. These are set at roughly 3/4 of the page width, leaving the social block isolated far left.
- Below these columns, a "Company" sub-section with additional links

**Lower footer band:**
- Far-left: Copyright notice + company address (two lines, small gray)
- Center-right: Three legal links (Cookie policy, Terms, Privacy Policy) — light gray, small
- Below that, a full-width legal disclaimer paragraph in small gray type — spans roughly half the page width

The two bands are separated by generous vertical spacing, not a rule or divider.

---

## 6. Notable Layout Patterns

**Oversized typographic elements as texture** — Both the hero wordmark and the editorial section header are set so large they bleed off the viewport. Type becomes image.

**Asymmetric column logic** — Multiple sections leave the left 30–40% of the page empty, aligning content to the right half. This creates a consistent right-lean gravity throughout the page, interrupted by the triptych section which resets to full-width.

**Full-bleed triptych panel** — The three-panel services section is the only place the page fully abandons the grid for pure color-blocked columns. It acts as a hard visual reset between the editorial top half and the feature sections below.

**Floating z-layer composition in the hero** — The hero is the only section where elements explicitly overlap across multiple depth layers. Elsewhere, sections are flat and contained.

**Carousel indicator as ghost UI** — The image carousel has no bounding box, no controls panel. The counter sits directly over the image, nearly camouflaged — trusting the user to discover it.

**Dark-light-dark rhythm** — The page moves from light hero → light content sections → dark services panel → light items → dark feature section → light experience section → dark footer. This alternation provides pacing without relying on transitions.
