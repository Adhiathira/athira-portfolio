# Brand Name Website — Layout Brief

## Overall Page Structure

The page is a vertically stacked, full-bleed cinematic scroll experience. Each section occupies close to 100vh, functioning more like a slideshow of immersive scenes than a traditional web page. There are approximately 6–7 distinct content sections, each anchored by a hero-scale background image or video with overlaid typography. The dominant rhythm is: full-bleed visual → text + CTA in corner or edge → transition to next full-bleed visual.

---

## Header / Navigation

**Sticky, minimal, full-width bar.**

- Left: Logo (wordmark + icon), anchored to left edge with comfortable padding
- Center: Primary nav links in small-caps, evenly spaced — horizontal row, generous letter-spacing
- Right: A single pill-shaped utility element (contextual live data or status indicator)
- Background: transparent/dark background, no visible border — blends into the dark hero beneath
- Height: compact, roughly 60–70px — not imposing, lets the imagery breathe

The navigation reads left-to-right with clear visual weight hierarchy: logo anchors left, utility info anchors right, nav links occupy the center as secondary elements.

---

## Hero Section

**Full-bleed, single-column with bottom-left content block.**

- The hero is a full-viewport image with no crop containment — it bleeds edge to edge and top to bottom
- Text block is positioned in the **lower-left quadrant**, roughly 1/3 width, with generous breathing room from the edges
- Headline: two-line all-caps statement in very large, bold light type — strong typographic mass against the dark left half of the image
- Body copy: a short paragraph in smaller weight beneath the headline, ~60–70 char line width
- CTA: an outlined Primary CTA button with arrow icon, sitting just below the body text
- **No split layout** — the image is the full canvas, and the text floats over the lower-left. The hero subject sits in the right half, creating a natural left–right compositional split without hard columns

## Content Sections (Below Hero)

### Section 2 — Key Differentiator Statement

**Full-bleed with center-right text block.**

- Background: dramatic brand photography, warm tones
- Content block shifts to **center-right** — roughly 55–100% horizontal span
- Same pattern: large all-caps headline (lighter opacity/weight on a bright background), body paragraph, outlined Primary CTA
- The text floats over the image with no background card or scrim — relies entirely on image composition leaving visual space for the type
- This alternating left/right placement of text creates spatial rhythm across sections

### Section 3 — Brand Value Proposition

**Full-bleed, split-visual with left text block.**

- Image: dramatic environmental or product photography with subject in the right half
- Text returns to **lower-left**, maintaining the alternating cadence
- Slightly lighter/translucent quality to the section — the image has cooler tones creating a tonal shift from previous section
- Same three-element stack: headline → body → Primary CTA

### Section 4 — Feature A

**Full-bleed, center-right text over dark imagery.**

- Left half: cinematic close-up detail shot — occupies roughly 40% of frame, bleed to left edge
- Right half: dark background, giving maximum contrast for light text
- Text block right-aligned in the upper-right quadrant — a deliberate flip from previous positioning
- This section feels more intimate and portrait-like compared to the wide landscape shots above

### Section 5 — Split-frame cinematic panel

**Horizontal split — two stacked image panels with no text.**

- The viewport is divided into two equal horizontal bands, each showing a different video/image
- Top half: close-up detail imagery
- Bottom half: structural or contextual imagery
- **No text, no CTA** — purely visual transition/interlude
- Functions as a breathing moment and pacing device between content sections

### Section 6 — Feature B / Product Name

**Full-bleed with upper-left text block.**

- Background: dark, dramatic product or technical imagery
- Text returns to the **left side**, upper portion of the viewport — a higher vertical position than prior sections
- Same headline → body → Primary CTA pattern
- The dark background with the imagery creates the highest contrast of the page — feels slightly more "product" than "mission"

## Footer

**Minimal, full-width, dark bar.**

- Two-column-ish: social icon anchored far left, copyright ("© [Year] Company") anchored far right
- Center: a small set of flat text links — evenly spaced in a single horizontal row
- Very low visual weight — almost disappears against the final section's dark background
- Height: roughly 60–70px, mirroring the header's proportions for visual bookending

## Notable Layout Patterns

**Full-bleed imagery as primary layout device.** Every section uses photography/video as the structural layer — there are no background colors, cards, or containers. The images *are* the sections.

**Floating text blocks without backgrounds.** All text overlays rely on image composition for contrast — no frosted glass, no dark overlays, no card containers. This requires tight art direction but creates a seamless, editorial quality.

**Left/right alternation of text positioning.** The content blocks rhythmically shift sides — lower-left, center-right, lower-left, upper-right, upper-left — creating a visual zigzag that keeps the eye moving and prevents monotony across what is otherwise a very repetitive template.

**Proportional consistency.** Every section uses the same three-element stack (headline → body → CTA), the same button style, and similar type scales. The layout template is fixed; only the position and background change. This creates strong brand coherence through repetition.

**Cinematic interlude panels.** The split-frame section with no text acts as a visual palate cleanser — a pacing mechanism borrowed from film editing rather than traditional web layout.

**Sticky utility element.** The live data indicator in the header is a sticky floating element that persists through scroll, adding dynamism without disrupting the clean nav structure.
