What it is

Built over three years without public announcement. Now quietly powering 14 independent publications across Europe and Japan.

Verge & Signal was built by a single art director for a specific problem: no existing publishing tool preserved the typographic and compositional precision that serious editorial work requires. Version 1 launched in 2022 with no press, no launch tweet. Word spread by referral only.

Precision publishing infrastructure.

Typography

Optical grid control

Every publication runs on a configurable optical grid — not a CSS grid approximation. Column widths, baseline intervals, and letter-spacing are set at the token level and respected by the renderer across digital and print export.

8
Design dimensions per publication

Color

Registered palette system

Colors are registered with luminance verification. Light and dark registers are enforced at the system level — no accidental contrast failures.

Motion

Duration-scaled animation

Motion tokens are scaled at the system level. Slowing or accelerating the entire publication's timing takes one token change, not 47 class overrides.

Access

Referral-gated

Membership is not purchased. It is extended. Every new member joins because an existing one chose to share access.

Output

Digital + print, same token source

The same design token set drives the digital publication, the PDF print master, and the export layer for external distribution. One source of truth. No reformatting step between digital production and print delivery.

SIGNAL

The tool does not announce itself.

Most publishing platforms have opinions about how your publication should look. Verge & Signal has no opinion. It is a neutral precision instrument. The editorial decisions — proportion, pace, accent — belong entirely to the person using it.

The UI is deliberately sparse. The system does not surface default templates, starter layouts, or suggested type pairings. You bring the design. It holds it faithfully at scale.
